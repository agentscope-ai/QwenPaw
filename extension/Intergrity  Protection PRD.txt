一、人格完整性保护
目的：保护AGENTS.md、SOUL.md、PROFILE.md 等人格基线不被破坏，防止prompt投毒
1、利用thirdparty目录下clawsec的soul_guardian能力对 AGENTS.md、SOUL.md、PROFILE.md 等建基线、漂移检测，防prompt层投毒，以免改人设让 agent「自愿」绕过策略）
2、文件被修改后要能立刻在前端提醒用户（利用 qwenpaw 的 SSE watch 机制），并提供接受修改和恢复按钮；用户点击恢复则还原到修改前的版本；用户点击接受则建立新的基线。
3、认知文件保护范围包含 AGENTS.md、SOUL.md、PROFILE.md 等，同时支持动态配置，以后可以增加扩展保护 skill 文件。
4、程序启动时进行一次全量扫描（仅 persona_protection_enabled=true 时）
5、本功能在前台界面支持开关，且开关默认关闭；开关开启后功能使能。
6、界面部署参考第四章 界面部署

三、健康体检
目的：对 qwenpaw 进行健康体检
1、入口：设置/安全 → 「健康检查」Tab（与工具防护、文件防护、完整性校验同级）
2、扫描：点击「Run check」触发只读扫描（POST /config/security/integrity-protection/health-check/scan，deep=false）
   - 扫描中：进度区轮播当前检查项（约 1.8 秒切换）
   - 完成后：汇总行 + 分组表格（Category / Check / Status / Details / What to do / Action）
   - 支持「Issues only / All」视图；环境类 OK 项可折叠
   - 上次结果保存在浏览器 sessionStorage（同会话刷新仍可见）
   - 扫描不修改任何用户文件
3、修复：有 fix_id 的项可点「Fix」
   - 普通 fix：Popconfirm 二次确认后调用 POST .../health-check/fix
   - 高风险 fix（如 seed-missing-agent-json、rebuild-console-npm 等）：Modal 二次确认
   - 仅允许 CONSOLE_FIX_IDS 白名单内的 doctor fix id
   - 无 fix 的项：显示 Manual fix 或跳转到 Tool Guard / File Guard / Skill Scanner Tab
4、体检范围：复用 qwenpaw doctor 结构化检查（extension/health_check/projection.py），非 CLI 文本解析
5、Deep 扫描：后端 API 支持 deep=true（含通道连通性、本地 LLM 深度项）；Console 当前仅提供默认扫描（deep=false），无 Deep 扫描按钮
6、界面部署参考第四章 界面部署
