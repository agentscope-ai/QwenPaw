# 非正式发布会字幕与花字

提供现代产品发布会的字体设计知识，用有色彩、有材质、有节奏的片内花字衬托主体的俏皮表现。它是现有 Creator 工具使用的模板专属 Skill，不是新 Agent、specialist 或独立制作流程。用户指定的配色、字体、位置和局部修改优先于默认建议。

## 使用方式

主 Agent 或剪辑导演使用本技能时，在现有 Overlay 的 `creation.text` 写完整中文与对应英文，`creation.prompt` 描述本镜的字体材质、重点词、入场和稳定期效果；使用已有 `design_motion_overlays` 结合实片生成文档。该工具也会自动读取本技能，无须增加委派或把产物重新上传。已有且符合需求的自定义设计继续保留；只有用户希望改样式或文案时才按现有编辑流程修订对应字幕。

中英文及不同标签组优先用换行分隔。历史文案中两侧带空白的 ` / ` 是组间排版分隔符，工具会在 `screenCopy` 中转为换行，不要求在画面上额外绘制斜杠。词语或数值内部的斜杠（例如 `24/7`、`AC/DC`）仍是正文，必须保留。

在字幕设计工具中，输入包含 `screenCopy`、`designIntent`、`actualTimeRangeSeconds`、`durationSeconds`、本片上下文和按时间排序的真实视频帧。此时直接设计当前一组字幕，并按文末契约返回 JSON，不输出计划或调用其他工具。

**每次只设计当前字幕。** `screenCopy` 是本次唯一上屏文案来源；`captions`、`story` 和其他镜头的文案仅供理解全片风格，绝不能一起画进当前文档。保留 `screenCopy` 的全部字词、标点和英文原始大小写，只调整换行与视觉层级；需要全大写外观时用 CSS `text-transform`，不要改写 DOM 里的英文。核对一次 HTML 的全部可见文字，忽略排版空白后应与本次 `screenCopy` 完全相同。

当前文档会从 0 秒直接渲染：第一组必须从可见状态入场，根容器保持 `opacity:1`，首组的基础样式和 keyframes 起点均至少为 `opacity:.25`。其他组可以稍后出现。所有入场与流光都是有限次动画，完整显示后保持；不要使用 `infinite` 或在末尾消失。

## 默认视觉方向

- **彩色字体是主视觉。** 主要中文标题和重要关键词主动采用清楚可见的渐变、珠光或金属质感；英文、说明和次要标签可以使用深色或浅色纯色建立层级。不能把全片做成同一种黑字加透明度淡入，渐变也不能只存在于一条细线或微小图标上。用户偏好更素的风格时按其要求降低强度。
- **先定本片配色，再变化表现。** 从主体、服装、环境和情绪挑选少量主色形成全片字体语言。同一色系可有双向渐变、关键词异色与局部高光，不需要每镜换一套彩虹。示例方向包括莓紫到靛蓝、深青到蓝绿、酒红到暖金；这些不是固定色板，狗、猫和其他主体都应重新选色。
- **亮背景使用有深度的彩色字。** 浅灰棚拍上优先饱和的中深色渐变，渐变两端与中段都要有对比；不用大面积白银或浅青字融进背景。深背景可用较亮的珠光、金属高光和轻微外发光。流光只作短促窄高光，扫过时字形仍完整可认；炫酷不能以持续发灰或闪到看不清为代价。
- **用字重与比例产生现代感。** 中文标题可用紧凑、有力量的无衬线粗体，关键词比连接词更大；英文用较轻字重与适量字距承接，不与中文争抢。可用 PingFang SC / Noto Sans CJK SC / Microsoft YaHei / sans-serif，英文可用 Arial / sans-serif。使用运行环境已有字体，不请求网络字体。

## 字形材质与运动

按语义选择并组合，不固定镜头顺序、效果数量、坐标或内部类名，也不要求轮换预设。

| 表达目的 | 可采用的字体与动效 |
| --- | --- |
| 主题亮相、主角名称 | 大号多色渐变字；标题与名称错峰揭示；一次窄幅珠光扫过字面，随后保留彩色字形 |
| 特征或卖点 | 让关键词成为渐变焦点；逐词抬升或短距离滑入；从细描边向实心色过渡，辅助英文稳定承接 |
| 俏皮镜头、趣味反应 | 弹性缩放、轻微倾斜回正、重音词跳入；可加贴近笔画的小星光或短光线，不用大卡片和随机粒子铺满画面 |
| 多套装扮标签 | 各款从共同色板或实际衣物取强调色，标签错峰到齐；可以轻扫光，但款式名称和对应英文要尽早稳定可读 |
| 片尾收束 | 沿用主题渐变，以短距离聚合、字距收拢或一次细光收束，结束时保留完整中英文 |

- **运动要能被看见，也要能停下来阅读。** 先快速形成文字，再有一次重点变化或短促流光，最后完整保持。可参考 0.3–0.8 秒入场、数十毫秒的逐字错峰和约 0.5–1 秒扫光，按当前文案长度与镜头时长调整；这些是节奏起点，不是固定参数。不要让所有字幕只有相同的淡入平移。
- **光效附着于字形。** 可用多层 `linear-gradient`、`background-clip:text` 和有限次 `background-position` 动画表现有色基底与窄高光；高光移动后基底仍须覆盖全部笔画。可用细描边或小范围柔光增加质感，避免粗黑描边、大片光晕和白色矩形扫过画面。
- **表现力来自原文字形。** 可逐字包裹 `span`、按词组分层或用小幅 scale/rotation；同一文案只在可见 DOM 中出现一次。不要复制整句制造重影、把文字塞进伪元素、增加 OK/PASS 等未请求的印章。无字图形不盖住任何中英文字框。
- **与笑点和阅读节奏配合。** 动作关键时刻可留白，结果出现后才强调短标题；造型段全部亮相后应有至少约 3 秒完整标签阅读，不能为扫光或逐字入场消耗掉阅读期。短字幕选更快的效果，长句先合理换行，不缩成小字。

## 实片排版与人工微调

先观察全部实帧中的主体位置、运动方向、镜头细节及互动道具。设计意图中的“右侧留白”等只是原构想，实片证据和用户后续指定优先；猫停下后空出的区域不代表走入时也为空。

原视频始终全屏，透明字幕在片内自由排版，不缩小或平移原片给文字腾位置，不加外栏、气泡边框或大块不透明底板。保护眼睛、鼻口、当前展示的关键特征与互动接触点；大特写允许文字与耳朵边缘或身体适度重叠，只要清楚可读。可接受的局部遮挡交由用户补充位置等信息微调，不作为反复重做整片的理由。

中文与英文按给定内容完整对应。主副组之间有明确间距，英文按完整单词换行。按词组换行、改变字号层级或安排分时呈现，避免交叉、裁字和省略号。根容器透明且始终 `opacity:1`；只有正在入场的字组可以降低透明度，稳定期两种语言都达到正常清晰度。

## 文档与渲染契约

当输入为单组字幕设计任务时，只返回一个 JSON 对象：

```json
{
  "needed": true,
  "format": "html_css",
  "html": "完整独立 HTML 文档",
  "concept": "本镜选用的字形材质、运动节奏和实片排版依据",
  "location": {"x":0.5,"y":0.5,"width":1,"height":1,"anchor_x":0.5,"anchor_y":0.5},
  "fps": 24,
  "loop": false
}
```

- `location` 是透明的完整字幕画布，文字自身在 HTML 内自由排版；不返回 `blueprint` 或预设编号。`html/body` 设透明背景、`margin:0`、`width/height:100%`、`overflow:hidden`；不嵌入背景视频、图片、iframe、网络资源或 emoji。
- 使用 `vw/vh/%` 或相对画布的单位，兼容导出与小预览。中文主标题可从画布宽度约 3.5%–6.5%、英文约 1.6%–2.4% 起步，按镜头和文案调整；四周及运动轨迹保留安全边距，不能依赖外溢显示。
- 给定 `screenCopy` 的中英文必须完整且只出现一次，阅读顺序与 DOM 一致。可改变视觉层级和换行，不新增、删改或隐藏文字以通过校验。制作指令不进入文案。
- 动画从本 Overlay 的 0 秒开始。首帧至少一组有可见内容（例如字组 `opacity:.25`），入场后达到 1；CSS 使用有限时长与次数，`animation-fill-mode:both/forwards`，最后保持所有文字完整可见。流光停在不破坏底色的位置，不用无限闪烁。
- 退场只在根容器声明 `data-motion-exit="soft_fade"`、`"shrink"` 或 `"none"`，由现有渲染器处理；CSS/GSAP 自身末态不归零、不移出或收拢成空帧，避免双重退场。
- `html_css` 使用 CSS keyframes，不包含脚本，JSON 只编码一次；解析后 style 中应为真实换行。复杂编排可用 `format:"html_js"`，仅引入 `vendor/gsap.min.js`，构建一条 paused 时间线并注册 `window.__hf={duration,seek(t,o)}`；`seek` 直接同步时间线，不依赖回调、墙钟、计时器、随机数或网络请求。
- `actualTimeRangeSeconds` 和实帧是当前时段；`timingEvidence` 已对齐实片时，不沿用剧本旧秒数延迟字幕。提交前检查入场、流光高光经过、稳定期与末态，确保字形完整、对比清楚、相邻文字不交叉。
