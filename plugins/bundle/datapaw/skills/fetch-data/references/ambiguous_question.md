# 常见歧义问题

本文档记录了几种用户数据分析问题中常见的歧义问题，若遇到此类问题，应抛出问题以及待确定的选项，让用户确认。

## 歧义问题

### 1. 意图不明

用户提出的数据分析意图不明确，数据中存在多个可选项能够符合分析意图。

#### 1.1. 数据分析指标指向不明

**问题描述**：用户提出的数据分析问题中指标指向不明确，存在多个可选指标符合数据分析需求。例如，用户提出对“留存率”指标分析，数据中可用指标包括“访问留存率”、“使用留存率”等。

**解决方法**：抛出问题以及待确定的选项（即，所有可用指标），让用户确认。

#### 1.2. 指标聚合粒度不明

**问题描述**：用户提出的数据分析问题中指标聚合粒度不明确，存在多个可选聚合粒度符合数据分析需求。例如，用户需要计算一段时间的对话用户数，聚合粒度可以是“日均对话用户数”、“该时间段内对话用户数总和”。

**解决方法**：考虑以下几种情况：

- 在 BI 场景中，计算一段时间内的 xx 人数/次数等统计值，聚合粒度默认为日均值，如，“日均对话用户数”

- 在 BI 场景中，计算环比/同比等指标时，基础数据聚合粒度默认为均值。如计算对话次数月环比，使用“该时间段内日均对话次数”作为基础数据。

如不被上述情况覆盖，则抛出指标聚合粒度的歧义问题以及所有可用聚合粒度，让用户确认。

#### 1.3. 数据维度指向不明

**问题描述**：数据中多个维度可用于数据筛选。例如，分析“文本对话的点赞率”，“对话模式”和“对话类型”两个维度都包含“文本对话”的维度取值。

**解决方法**：抛出问题以及待确定的选项（即，所有可用维度），让用户确认。


### 2. 数据来源不明

#### 2.1. 数据表来源不明

**问题描述**：数据中多个数据表在指标计算、数据维度选择等都满足数据分析需求。例如，分析“计算 wan 不同端 dau 指标”，表 `dws_ty_wanx_dau_index_1d` 和 `dws_ty_wanx_dau_distribution_1d` 都包含可用于计算 dau 指标都数据，且包含指向不同端的字段，即两张表都可用于数据分析。

**解决方法**：考虑以下情况：

- 优先考虑数据分析的需求（指标计算、维度选择等），选择可满足所有要求的数据表

- 在多张表满足数据分析要求的情况下，根据每张表的描述，选择最符合数据分析需求的数据表

- 优先考虑能够最准确计算指标的数据表组合，而不是优先考虑能够计算某一“代理指标”的数据表

- 仍有多张表满足要求的情况下，**必须**优先选择`overview`、`index`等概览表进行组合求解，这些表通常包含最全的指标和维度，且计算方式较为简单；慎重考虑 `distribution`、`lightsummary` 等其他聚合表，这些表根据某一特定分析任务聚合，可能无法准确计算 dau 指标。
