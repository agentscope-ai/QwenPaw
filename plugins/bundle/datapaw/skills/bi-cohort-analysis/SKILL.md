# bi-cohort-analysis

将具有相同起始特征的用户划分为同期群，并跟踪各群在后续时间窗口内的表现差异。

## 前置条件

开始执行前，确认以下信息已就绪：

- **分析对象**明确，通常为「用户」，且能唯一标识（如 `user_id`）
- **起始特征**已确定，即划分同期群所依据的入口属性（如注册渠道、首单金额、首日行为、获客活动等）
- **后续表现指标**已确定，即 cohort 形成后要跟踪的业务指标（如留存率、转化率、LTV、复购次数等）
- **数据获取能力**可用，能取到对象级起始特征数据及对应后续表现数据

若起始特征或跟踪指标不明确，需先回到规划阶段补充，或向用户确认后再开始执行。

## 分析原则

### 同期群定义

同期群（cohort）指在相同时点或具备相同起始特征的用户集合。本 workflow 通过 **起始特征分群** 定义 cohort，再比较各 cohort 在 **后续时间窗口** 内的指标表现。

### 主要步骤

| 步骤 | 用途 |
|------|------|
| 分群 | 按起始特征将用户划分为若干 cohort |
| 对比 | 对各 cohort 的后续表现指标做定量对比 |

本 workflow 主要提供 cohort 场景下的编排与数据衔接逻辑，各步骤的具体执行按相应分析方法的标准流程进行。

---

## 1. 确定起始特征与跟踪指标

1. **起始特征**：选定用于定义 cohort 的维度（一个或多个）。常见示例：
   - 获客渠道、注册版本、首单金额区间
   - 首日关键行为（是否完成引导、是否付费等）
   - 多特征组合时优先走聚类路径（见步骤 2）

2. **跟踪指标**：明确 cohort 形成后要观测的后续指标及时间窗口（如 D7/D30 留存、30 日内 LTV、首周转化率等）。

3. **对象粒度**：确认一行对应一个待分群用户；若原始数据为事件级，先聚合到用户级。

---

## 2. 按起始特征分群

以步骤 1 确定的起始特征为输入，完成用户分群。

### 数据准备

整理 CSV，包含：

- 对象标识列（如 `user_id`）
- 起始特征列（波士顿矩阵法需 2 列；聚类法可有多列数值特征）

### 分群执行

- **两维策略型分群**（如「增长 × 份额」）：优先波士顿矩阵法
- **多维综合分群**：优先 K-means / 分层聚类 / DBSCAN

分群结果保存为 JSON，键为 `"cluster 1"`、`"cluster 2"` 等，值为该 cohort 内的用户 ID 列表（供步骤 3 按 `user_id` 关联）。

### 产出检查

- [ ] 各 cohort 样本量可解释，无异常空簇（DBSCAN 噪声点单独标注）
- [ ] 起始特征与分群方法在结论中可复现

---

## 3. 准备后续表现数据

基于步骤 2 的分群结果，为每个 cohort 汇总后续表现指标：

1. 将分群 JSON 与用户级后续指标表按 `user_id` 关联
2. 按 cohort 聚合跟踪指标（如 cohort 均值、中位数、率值指标的分子/分母汇总等）
3. 整理为 **对比分析用 CSV**：每列对应一个 cohort（或参照 cohort），每行对应一个时间点或汇总口径

示例（三群 D7 留存率对比）：

```csv
指标,cohort_1,cohort_2,cohort_3
D7留存率,0.42,0.38,0.51
```

若需与总体或某一基准 cohort 对比，在 CSV 中一并纳入参照列。

---

## 4. 跨 cohort 对比分析

对步骤 3 整理的数据执行对比分析。

### 分析要点

- **比较维度**：通常为 **空间对比**（横向比较不同 cohort 之间差异）
- **基准设定**：明确参照 cohort（如总体、最大群、或业务指定的对照群）
- **计算方式**：按指标类型选择绝对差值或相对差值；多 cohort 间不遗漏任一对比对
- **显著性**：样本为多个用户或多次观测时，按显著性检验规则执行 t / z / 卡方检验

保存对比分析结果。

---

## 5. 汇总结论

完成以上步骤后，按顺序汇总：

| 字段 | 说明 |
|------|------|
| 执行内容 | 本步骤做了什么 |
| 取数文件 | 起始特征数据、后续表现数据路径 |
| 中间产物 | 分群 JSON、对比用 CSV 路径 |
| 计算结果 | 对比分析结果路径 |
| 结论 | 各 cohort 的起始画像、后续表现差异及显著性 |

汇总结构建议：

1. **Cohort 划分**：分群方法、起始特征、各群规模与占比
2. **起始画像**：各 cohort 在起始特征上的差异（辅助解读分群合理性）
3. **后续表现对比**：各 cohort 在跟踪指标上的水平、差异幅度与显著性
4. **业务解读**：表现最优/最劣 cohort 的可能原因与可执行建议
5. **局限与不确定性**：样本量、时间窗口、特征选择、分群稳定性等
