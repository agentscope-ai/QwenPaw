# BI 指标细化指引

本文档供 analysis-plan-builder 在 Step 1.5 使用，用于对已确认的 BI 分析模块进行指标细化（确定指标 + 分配角色）。

---

## 指标类型

| 角色       | 说明                                               |
| ---------- | -------------------------------------------------- |
| 北极星指标 | 核心监测指标，需要深度分析（异常检测、维度拆解等） |
| 展示指标   | 常规观测指标，展示数据和衍生指标                   |
| 分布指标   | 需要展示各维度下的分布和占比的指标                 |

每个指标至少分配一个角色，也可同时具有多个角色（如北极星 + 分布）。每个模块的北极星指标通常 1-3 个，不宜过多。

---

## 指标和角色判定

按以下优先级依次查找每个模块的**指标**及其**角色**，命中即停：

| 优先级 | 来源                                                                                                                                                               | 取指标                       | 取角色                                                 |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------- | ------------------------------------------------------ |
| 1      | 用户问题（若存在）                                                                                                                                                 | 用户明确提到的指标，直接采用 | 用户语气判断（如"重点看" → 北极星，"顺便看" → 展示） |
| 2      | 域知识包（若存在）                                                                                                                                                 | 域知识包中该模块定义的指标   | 域知识包中标注的角色                                   |
| 3      | 语义层（若可用）                                                                                                                                                   | 查询该模块相关指标并验证     | 语义层标注的角色                                       |
| 4      | `references/metrics/`目录下的业务框架文档：`<br>` ToC → `toc.md` `<br>` ToB → `tob.md` `<br>` ToD → `tod.md` `<br>` Mixed → 读取涉及的多个文件 | 指标表中的推荐指标           | 指标表中的默认角色列                                   |
| 5      | 默认                                                                                                                                                               | 根据模块名推断常见指标       | 根据指标特征推断角色                                   |
