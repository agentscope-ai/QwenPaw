# ToB 业务 - 默认指标表

## 规模与健康度

| 指标类别 | 关键指标                 | 默认角色 | 分析目的       |
| -------- | ------------------------ | -------- | -------------- |
| 客户规模 | 企业客户总数、活跃企业数 | 展示指标 | 判断市场渗透   |
| 客户规模 | 付费企业数               | 北极星指标 | 核心收入来源   |
| 客户分层 | 大/中/小B客户数及占比    | 分布指标 | 识别收入集中度 |
| 用量规模 | 总调用量、单客户平均用量 | 展示指标 | 评估产品渗透   |
| 增长质量 | 收入留存率、收入续约率   | 北极星指标 | 判断业务健康度 |
| 增长质量 | 流失率                   | 展示指标 | 监控客户流失   |

## 财务表现

| 指标类别 | 关键指标             | 默认角色 | 分析目的       |
| -------- | -------------------- | -------- | -------------- |
| 收入侧   | GMV、GAAP、ARR/MRR   | 北极星指标 | 衡量商业化规模 |
| 成本侧   | 总成本、单位经济成本 | 展示指标 | 评估成本结构   |
| 利润侧   | 毛利、毛利率         | 展示指标 | 判断盈利能力   |

## 默认模块 → 指标映射

| 模块           | 推荐指标                 | 推荐归因维度                 |
| -------------- | ------------------------ | ---------------------------- |
| 用量与规模分析 | 客户数, 付费企业数, 用量 | 客户分层, 行业, 区域, 产品线 |
| 客户分析       | 客户分层占比, 转化链路   | 客户分层, 行业               |
| 客户健康度分析 | 留存率, 续约率, NRR      | 客户分层, 产品线, 区域       |
| 财务分析       | ARR/MRR, 成本, 毛利      | 客户分层, 产品线, 区域       |
