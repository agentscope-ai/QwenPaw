# ToB 业务 - 默认指标表

## 规模与健康度

| 指标类别 | 关键指标                 | 指标类型 | 默认角色     | 分析目的       |
| -------- | ------------------------ | -------- | ------------ | -------------- |
| 客户规模 | 企业客户总数、活跃企业数 | quantity | display      | 判断市场渗透   |
| 客户规模 | 付费企业数               | quantity | north_star   | 核心收入来源   |
| 客户分层 | 大/中/小B客户数及占比    | quantity | distribution | 识别收入集中度 |
| 用量规模 | 总调用量、单客户平均用量 | quantity | display      | 评估产品渗透   |
| 增长质量 | 收入留存率、收入续约率   | ratio    | north_star   | 判断业务健康度 |
| 增长质量 | 流失率                   | ratio    | display      | 监控客户流失   |

## 财务表现

| 指标类别 | 关键指标             | 指标类型       | 默认角色   | 分析目的       |
| -------- | -------------------- | -------------- | ---------- | -------------- |
| 收入侧   | GMV、GAAP、ARR/MRR   | quantity       | north_star | 衡量商业化规模 |
| 成本侧   | 总成本、单位经济成本 | quantity       | display    | 评估成本结构   |
| 利润侧   | 毛利、毛利率         | quantity/ratio | display    | 判断盈利能力   |

## 默认模块 → 指标映射

| 模块           | 推荐指标                 | 推荐归因维度                 |
| -------------- | ------------------------ | ---------------------------- |
| 用量与规模分析 | 客户数, 付费企业数, 用量 | 客户分层, 行业, 区域, 产品线 |
| 客户分析       | 客户分层占比, 转化链路   | 客户分层, 行业               |
| 客户健康度分析 | 留存率, 续约率, NRR      | 客户分层, 产品线, 区域       |
| 财务分析       | ARR/MRR, 成本, 毛利      | 客户分层, 产品线, 区域       |

## 归因分析框架

```
收入变化 = 客户数变化 × 单客户用量变化 × 单价变化
成本变化 = 规模驱动 + 结构驱动 + 效率驱动
```
