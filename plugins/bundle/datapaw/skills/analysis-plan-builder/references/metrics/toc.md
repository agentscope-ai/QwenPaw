# ToC 业务 - 默认指标表

## 用户体验与健康度

| 指标类别 | 关键指标           | 默认角色 | 分析目的         |
| -------- | ------------------ | -------- | ---------------- |
| 满意度   | NPS、满意度        | 展示指标 | 衡量用户主观体验 |
| 使用深度 | DAU/MAU            | 北极星指标 | 评估产品粘性     |
| 使用深度 | 使用时长、使用频次 | 展示指标 | 评估使用深度     |
| 使用深度 | 功能渗透率         | 展示指标 | 评估功能覆盖     |
| 留存表现 | 次日/7日/30日留存  | 北极星指标 | 判断长期价值     |
| 流失预警 | 流失率             | 展示指标 | 识别风险用户     |

## 增长与渠道效率

| 指标类别 | 关键指标               | 默认角色 | 分析目的     |
| -------- | ---------------------- | -------- | ------------ |
| 增长规模 | DAU、MAU               | 北极星指标 | 衡量增长势头 |
| 增长规模 | 新增用户数、净增用户数 | 展示指标 | 衡量增长来源 |
| 渠道效率 | 各渠道 CAC、ROI        | 展示指标 | 优化投放     |
| 渠道效率 | 转化率漏斗             | 展示指标 | 分析转化瓶颈 |

## 变现平衡（如有收费）

| 指标类别 | 关键指标       | 默认角色 | 分析目的       |
| -------- | -------------- | -------- | -------------- |
| 变现效率 | ARPU           | 展示指标 | 衡量商业化能力 |
| 变现效率 | 付费率、复购率 | 展示指标 | 评估付费转化   |

## 默认模块 → 指标映射

| 模块               | 推荐指标                        | 推荐归因维度               |
| ------------------ | ------------------------------- | -------------------------- |
| 用户趋势与规模     | DAU/MAU, 新增用户数, 净增用户数 | 渠道, 用户分层, 地域, 设备 |
| 用户结构及留存     | 留存率, 使用时长, 功能渗透率    | 用户分层, 功能, 渠道       |
| 使用行为及体验     | 使用频次, 功能渗透率, NPS       | 功能, 用户分层             |
| 用户转化与价值分析 | ARPU, 付费率, 复购率            | 用户分层, 付费等级         |
