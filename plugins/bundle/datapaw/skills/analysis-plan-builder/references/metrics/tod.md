# ToD 业务 - 默认指标表

## 供给规模与结构

| 指标类别 | 关键指标                   | 默认角色 | 分析目的       |
| -------- | -------------------------- | -------- | -------------- |
| 供给规模 | 活跃供给数（月活/周活）    | 北极星指标 | 衡量生态体量   |
| 供给规模 | 开发者总数                 | 展示指标 | 衡量累计规模   |
| 供给分层 | 头部/腰部/长尾供给数及占比 | 分布指标 | 识别生态健康度 |
| 供给质量 | 优质内容占比               | 展示指标 | 衡量内容质量   |

## 社区生态与互动

| 指标类别 | 关键指标                 | 默认角色 | 分析目的       |
| -------- | ------------------------ | -------- | -------------- |
| 社区活跃 | 社区 DAU/MAU             | 北极星指标 | 衡量社区活跃度 |
| 社区活跃 | 发帖率、回复率、互动率   | 展示指标 | 衡量互动密度   |
| 内容消费 | 浏览量、下载量、Fork 数  | 展示指标 | 衡量内容影响力 |
| 飞轮效应 | 优质供给的流量增益       | 北极星指标 | 验证飞轮闭环   |
| 生态健康 | 马太效应系数（基尼系数） | 北极星指标 | 预防生态恶化   |

## 默认模块 → 指标映射

| 模块           | 推荐指标                             | 推荐归因维度              |
| -------------- | ------------------------------------ | ------------------------- |
| 供给规模与结构 | 活跃供给数, 新增/流失供给, 供给分层  | 供给分层, 领域/模态, 地域 |
| 社区生态分析   | 社区 DAU/MAU, 互动率, 内容消费       | 内容类型, 领域, 供给分层  |
| 开发者生命周期 | 新增/活跃/流失开发者, 留存, 贡献深度 | 供给分层, 领域            |
| 变现价值分析   | 付费占比, 供给方收入, ARPU           | 供给分层, 内容类型        |
