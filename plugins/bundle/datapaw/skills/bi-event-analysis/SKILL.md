# bi-event-analysis

对用户在产品或业务流程中发生的关键行为进行计数、去重、聚合和分组，得到行为统计结果。旨在

- 了解用户行为发生情况
- 评估功能使用频率
- 识别核心行为与异常行为
- 为漏斗、路径、留存等分析提供基础数据

## 使用场景

- 分析事件发生绝对次数与绝对用户人数
- 计算事件发生频率（如：页面按钮点击率）
- 分析功能渗透率（如：功能使用群体与目标用户群体数量对比）

## fallback（指引模式）

无脚本环境时手动计算：

1. 事件发生次数：

$事件发生次数=\sum_i |事件i发生次数|$

2. 事件用户数：

$事件用户数=|\{用户 \mid 用户触发事件\}|$

3. 人均事件触发次数：

$人均事件触发次数=\frac{事件发生次数}{事件用户数}$

4. 渗透率

$渗透率=\frac{事件用户数}{|\{用户 \mid 用户属于事件目标群体\}|}$
