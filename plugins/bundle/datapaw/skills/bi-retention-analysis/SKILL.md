# bi-retention-analysis

对留存率变化执行完整的分析流程：按需分群 → 计算留存率 → 按需对比分析。

## 前置条件

开始执行前，确认以下信息已就绪：

- **留存锚点**明确，即用户首次进入产品或首次完成关键行为的时间点（day0）已定义
- **留存指标**已确定（如次日留存率、第 7 日留存率、访问留存、使用留存等），对应 day0 / dayn 口径清晰
- **数据获取能力**可用，能取到计算留存率所需的 CSV 或等价数据
- **分析范围**明确，包括时间窗口、对象范围，以及是否需要分群或跨维度对比

若留存锚点或指标口径不明确，需先回到规划阶段补充，或向用户确认后再开始执行。

## 分析原则

### 主要步骤

| 步骤 | 用途 | 是否必选 |
|------|------|----------|
| 分群 | 按特征将用户划分为若干群体 | **可选**，见步骤 1 |
| 计算 | 计算 day0 用户在 dayn 的留存率 | **必选** |
| 对比 | 跨时间、群体、地区等维度对比留存率差异 | **可选**，见步骤 3 |

本 workflow 主要提供留存率分析场景下的编排与数据衔接逻辑，各步骤的具体执行按相应分析方法的标准流程进行。

---

## 1. 决定是否分群

根据数据分析要求，判断是否需要对用户数据分群：

**需要分群** → 进行用户分群，完成后进入步骤 2  
**未要求分群** → **跳过本步骤**，直接进入步骤 2

### 判断依据

| 信号 | 示例 |
|------|------|
| 明确要求分群/聚类/客群划分 | 「按用户特征分群后看留存」「对不同类型用户的留存率进行分析」 |
| 需发现未知用户子结构 | 「哪些用户群体留存更高」「用户自然分群后的留存差异」 |
| 多维特征综合分群 | 需结合多个用户属性（消费、活跃、渠道等）划分群体再算留存 |

| 信号 | 示例 |
|------|------|
| 仅看整体或已有维度 | 「整体次日留存如何」「按国家/端/渠道看留存」（维度已在数据中，无需聚类） |
| 仅关注时间趋势 | 「最近一周留存率变化」（走步骤 3 时间对比，无需分群） |

### 分群执行（若启用）

1. 整理用户级 CSV：对象标识列 + 分群特征列
2. 对用户进行分群，结果保存为 JSON
3. 将分群结果与留存相关数据按用户 ID 关联，**按群分别准备**步骤 2 所需的 day0 / dayn 用户数数据

---

## 2. 计算留存率

计算用户在后续第 n 天的留存率。

### 数据准备

整理 CSV，包含留存率计算所需的列：

- **第 0 天用户数**（分母，如当日访问用户数、当日新增用户数）
- **第 n 天用户数**（分子，如次日访问用户数、第 7 日访问用户数）
- 若步骤 1 已分群：按群分别准备数据，或在同一 CSV 中按群拆分多组列

示例：

```csv
date,当日访问用户数,次日访问用户数
2025-01-01,10000,3000
2025-01-02,10500,1000
```

### 计算执行

- 对每个需要报告的留存率指标（如次日留存、第 7 日留存、访问留存 vs 使用留存）按留存率公式或可用脚本进行计算
- 不遗漏任何必要的留存率指标
- 保存计算结果

若步骤 1 已分群，**对每个 cohort 分别计算**留存率，保留各群及总体（若需要）的结果。

---

## 3. 决定是否做对比分析

根据数据分析要求，判断是否需对不同时间、群体、地区等进行留存率对比：

**需要对比** → 进行对比分析，完成后进入步骤 4  
**不需要对比** → **跳过本步骤**，直接进入步骤 4

### 判断依据

| 信号 | 示例 |
|------|------|
| 时间维度对比 | 「环比/同比变化」「最近 vs 历史」「留存率是否下降」 |
| 群体/空间维度对比 | 「不同国家/渠道/端/实验组留存差异」「访问留存 vs 使用留存」「A 群 vs B 群」 |
| 显式对比/差异/优劣 | 「对比」「差异」「哪个更高/更低」「是否显著」 |

| 信号 | 示例 |
|------|------|
| 仅报告当前水平 | 「当前次日留存是多少」「整体留存表现如何」（步骤 2 结果已足够） |
| 单一对象无参照 | 只有一个时间点、一个群体，无对比参照物 |

### 对比执行（若启用）

1. 基于步骤 2 的留存率结果，整理 **对比分析用 CSV**：
   - 时间对比：每列对应一个时期，或一列时间序列供环比/同比计算
   - 空间对比：每列对应一个国家/渠道/端/cohort/留存类型（访问 vs 使用）等
2. 选择合适比较维度（时间 / 空间 / 标准）与计算方式（绝对差值 / 相对差值）执行对比分析
3. 多样本时按显著性检验规则执行
4. 保存对比分析结果

示例（不同国家次日留存对比）：

```csv
业务日期,中国次日留存率,美国次日留存率
20251101,0.3856,0.4343
20251102,0.4288,0.4122
```

---

## 4. 汇总结论

完成以上步骤后，按实际执行路径汇总：

| 字段 | 说明 |
|------|------|
| 执行内容 | 本步骤做了什么（含跳过的可选步骤及原因） |
| 取数文件 | 原始数据路径 |
| 中间产物 | 分群 JSON（若执行）、对比用 CSV（若执行） |
| 计算结果 | 留存率及对比分析结果路径 |
| 结论 | 留存率水平、变化趋势、群体差异及显著性 |

汇总结构建议：

1. **分析范围**：时间窗口、留存锚点与指标定义、是否分群、是否做对比
2. **留存率结果**：整体及各维度/cohort 的留存率水平（含关键节点如次日、第 7 日）
3. **对比发现**（若执行步骤 3）：时间变化幅度、群体间差异、显著性结论
4. **业务解读**：留存表现评价、关键驱动因素与可执行建议
5. **局限与不确定性**：样本量、口径差异、分群稳定性、未覆盖维度等
