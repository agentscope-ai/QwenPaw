# bi-conversion-analysis

对转化率变化执行完整的分析流程：按需分群 → 计算转化率 → 异常分析 → 按需对比分析。

## 前置条件

开始执行前，确认以下信息已就绪：

- **转化漏斗**明确，即起始行为（接触目标行为）与结束行为（完成目标行为）已定义
- **转化率指标**已确定（如对话转化率、付费转化率等），对应分子/分母口径清晰
- **数据获取能力**可用，能取到计算转化率所需的 CSV 或等价数据
- **分析范围**明确，包括时间窗口、对象范围，以及是否需要分群或跨维度对比

若转化漏斗或指标口径不明确，需先回到规划阶段补充，或向用户确认后再开始执行。

## 分析原则

### 主要步骤

| 步骤 | 用途 | 是否必选 |
|------|------|----------|
| 分群 | 按特征将用户划分为若干群体 | **可选**，见步骤 1 |
| 计算 | 计算起始行为到结束行为的转化率 | **必选** |
| 异常分析 | 识别转化率时间序列中的异常波动点 | **可选** |
| 对比 | 跨时间、群体、地区等维度对比转化率差异 | **可选**，见步骤 4 |

本 workflow 主要提供转化率分析场景下的编排与数据衔接逻辑，各步骤的具体执行按相应分析方法的标准流程进行。

---

## 1. 决定是否分群

根据数据分析要求，判断是否需要对用户数据分群：

**需要分群** → 进行用户分群，完成后进入步骤 2  
**未要求分群** → **跳过本步骤**，直接进入步骤 2

### 判断依据

| 信号 | 示例 |
|------|------|
| 明确要求分群/聚类/客群划分 | 「按用户特征分群后看转化」「对不同类型用户的转化率进行分析」 |
| 需发现未知用户子结构 | 「哪些用户群体转化更高」「用户自然分群后的转化差异」 |
| 多维特征综合分群 | 需结合多个用户属性（消费、活跃、渠道等）划分群体再算转化 |

| 信号 | 示例 |
|------|------|
| 仅看整体或已有维度 | 「整体对话转化率如何」「按国家/端/渠道看转化」（维度已在数据中，无需聚类） |
| 仅关注时间趋势 | 「最近一周转化率变化」（走步骤 4 时间对比，无需分群） |

### 分群执行（若启用）

1. 整理用户级 CSV：对象标识列 + 分群特征列
2. 对用户进行分群，结果保存为 JSON
3. 将分群结果与转化相关数据按用户 ID 关联，**按群分别准备**步骤 2 所需的分子/分母数据

---

## 2. 计算转化率

计算从起始行为到结束行为的转化率。

### 数据准备

整理 CSV，包含转化率计算所需的列：

- **起始行为用户数**（分母，如访问用户数）
- **结束行为用户数**（分子，如对话用户数）
- 若步骤 1 已分群：按群分别准备数据，或在同一 CSV 中按群拆分多组列

示例：

```csv
date,访问用户数,对话用户数
2025-01-01,10000,3000
2025-01-02,10500,1000
```

### 计算执行

- 对每个需要报告的转化率指标按转化率公式或可用脚本进行计算
- 不遗漏任何必要的转化率指标
- 保存计算结果

若步骤 1 已分群，**对每个 cohort 分别计算**转化率，保留各群及总体（若需要）的结果。

---

## 3. 按需执行转化率异常分析

查看计算得到的转化率是否是时间相关的序列，若是，则对步骤 2 产出的转化率时间序列进行异常波动点识别，若否，则跳过本步骤。

### 数据准备

基于步骤 2 的转化率结果，整理含时间序列的 CSV，至少包含：

- **日期列**：时间标识
- **指标列**：转化率（如对话转化率）

示例：

```csv
date,对话转化率
2025-01-01,0.3000
2025-01-02,0.0952
2025-01-03,0.0095
```

若步骤 1 已分群，对需要报告的各 cohort 及总体分别准备时间序列并执行异常检测。

### 异常检测执行

- 按异常检测的对比逻辑（日异常检测建议同时检查日环比和周同比）
- 按优先级确定阈值（用户指定 → 域知识包 → 语义层 → 自适应）
- 按异常检测的标准原理或可用脚本自行实现
- 记录异常波动点、对应变化率及所用阈值

---

## 4. 决定是否做对比分析

根据数据分析要求，判断是否需对不同时间、群体、地区等进行转化率对比：

**需要对比** → 进行对比分析，完成后进入步骤 5  
**不需要对比** → **跳过本步骤**，直接进入步骤 5

### 判断依据

| 信号 | 示例 |
|------|------|
| 时间维度对比 | 「环比/同比变化」「最近 vs 历史」「转化率是否下降」 |
| 群体/空间维度对比 | 「不同国家/渠道/端/实验组转化差异」「A 群 vs B 群」 |
| 显式对比/差异/优劣 | 「对比」「差异」「哪个更高/更低」「是否显著」 |

| 信号 | 示例 |
|------|------|
| 仅报告当前水平 | 「当前转化率是多少」「整体转化表现如何」（步骤 2 结果已足够） |
| 单一对象无参照 | 只有一个时间点、一个群体，无对比参照物 |

### 对比执行（若启用）

1. 基于步骤 2 的转化率结果（可结合步骤 3 的异常点上下文），整理 **对比分析用 CSV**：
   - 时间对比：每列对应一个时期，或一列时间序列供环比/同比计算
   - 空间对比：每列对应一个国家/渠道/端/cohort 等
2. 选择合适比较维度（时间 / 空间 / 标准）与计算方式（绝对差值 / 相对差值）执行对比分析
3. 多样本时按显著性检验规则执行
4. 保存对比分析结果

示例（不同端转化对比）：

```csv
业务日期,web端转化率,app端转化率
20251101,0.7856,0.2343
20251102,0.2288,0.8822
```

---

## 5. 汇总结论

完成以上步骤后，按实际执行路径汇总：

| 字段 | 说明 |
|------|------|
| 执行内容 | 本步骤做了什么（含跳过的可选步骤及原因） |
| 取数文件 | 原始数据路径 |
| 中间产物 | 分群 JSON（若执行）、异常检测输入 CSV、对比用 CSV（若执行） |
| 计算结果 | 转化率、异常波动点及对比分析结果路径 |
| 结论 | 转化率水平、异常波动、变化趋势、群体差异及显著性 |

汇总结构建议：

1. **分析范围**：时间窗口、转化漏斗定义、是否分群、是否做对比
2. **转化率结果**：整体及各维度/cohort 的转化率水平
3. **异常发现**：异常波动点、变化幅度、所用对比逻辑与阈值
4. **对比发现**（若执行步骤 4）：时间变化幅度、群体间差异、显著性结论
5. **业务解读**：转化表现评价、关键驱动因素与可执行建议
6. **局限与不确定性**：样本量、口径差异、分群稳定性、未覆盖维度等
