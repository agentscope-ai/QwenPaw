# 显著性检验

## t 检验

```
H0: μ_A = μ_B （两组均值相等）
H1: μ_A ≠ μ_B （两组均值不等）

检验统计量：
t = (x̄_A - x̄_B) / √(s²_p * (1/n_A + 1/n_B))

其中 s²_p 为合并方差
```

## z 检验

```
H0: p_A = p_B （两组比例相等）
H1: p_A ≠ p_B （两组比例不等）

检验统计量：
z = (p̂_A - p̂_B) / √[p̂(1-p̂)(1/n_A + 1/n_B)]

其中 p̂ 为合并比例
```

## 卡方检验*

```
H0: 变量 A 与变量 B 独立
H1: 变量 A 与变量 B 相关

检验统计量：
χ² = Σ[(O - E)² / E]

其中 O 为观测频数，E 为期望频数
```

## 判断显著性

**决策规则**：

| p 值范围 | 结果 | 业务含义 |
|----------|------|----------|
| p < 0.01 | 极显著 (***) | 差异极大概率真实存在 |
| 0.01 ≤ p < 0.05 | 显著 (**) | 差异大概率真实存在 |
| 0.05 ≤ p < 0.1 | 边缘显著 (*) | 差异可能存在，需谨慎判断 |
| p ≥ 0.1 | 不显著 (ns) | 差异可能由随机因素导致 |

**效应量计算**：

| 检验类型 | 效应量指标 | 解释标准 |
|----------|------------|----------|
| t 检验 | Cohen's d | 0.2=小，0.5=中，0.8=大 |
| z 检验 | Cohen's h | 0.2=小，0.5=中，0.8=大 |
| 卡方检验 | Cramer's V | 0.1=小，0.3=中，0.5=大 |
