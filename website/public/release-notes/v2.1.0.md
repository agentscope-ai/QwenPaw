## ✨ Added

**QwenPaw OS Shell**

- Open apps in movable, resizable windows with a launcher, taskbar, notifications, and saved layouts ([#6645](https://github.com/agentscope-ai/QwenPaw/pull/6645))
- Installed and marketplace apps now share one catalog across the App Center and QwenPaw OS Shell ([#6718](https://github.com/agentscope-ai/QwenPaw/pull/6718))

**Unified Files Workspace**

- Browse, preview, edit, compare, upload, and download workspace files without leaving Chat ([#6504](https://github.com/agentscope-ai/QwenPaw/pull/6504))
- Open the Files workspace directly from QwenPaw OS Shell ([#6758](https://github.com/agentscope-ai/QwenPaw/pull/6758))
- Edit Robot Framework files with syntax highlighting ([#6519](https://github.com/agentscope-ai/QwenPaw/pull/6519))

**QwenPaw Creator**

- Turn an idea or existing footage into a finished video with a team of specialized Agents ([#6284](https://github.com/agentscope-ai/QwenPaw/pull/6284))
- Select clips, subtitles, effects, assets, or text for focused Agent edits while keeping direct controls ([#6740](https://github.com/agentscope-ai/QwenPaw/pull/6740))
- Create with images, video, voice, subtitles, motion, overlays, and parallel production steps ([#6740](https://github.com/agentscope-ai/QwenPaw/pull/6740))
- Add media task recovery, rendering fixes, structured logs, and review feedback ([#6556](https://github.com/agentscope-ai/QwenPaw/pull/6556), [#6641](https://github.com/agentscope-ai/QwenPaw/pull/6641))
- Add a settings center, external Skills, asynchronous media generation, more rendering formats, and improved Windows and narrow-screen support ([#6870](https://github.com/agentscope-ai/QwenPaw/pull/6870))

**Cross-harness Integration**

- Create Agents powered by Codex or Qoder, with per-session models, permissions, Skills, and MCP services ([#6397](https://github.com/agentscope-ai/QwenPaw/pull/6397))
- ACP clients can pass temporary models, project folders, and MCP services without saving runtime credentials ([#6754](https://github.com/agentscope-ai/QwenPaw/pull/6754))
- ACP sessions now report available and current models to compatible clients ([#6531](https://github.com/agentscope-ai/QwenPaw/pull/6531))

**Browser-use**

- Browser-use remains in Beta. It can use a separate browser session or connect selected tabs from the user's signed-in Chrome. Browser-side code execution is not protected by a host-level sandbox, and action policies are not yet enforced ([#6276](https://github.com/agentscope-ai/QwenPaw/pull/6276), [#6157](https://github.com/agentscope-ai/QwenPaw/pull/6157))

**Computer-use**

- Add Windows desktop app automation. macOS packaging and signing are complete, while device-level end-to-end validation is still in progress. Operations require per-app approval and stop when the user takes over input ([#6424](https://github.com/agentscope-ai/QwenPaw/pull/6424))
- Native Computer-use adds keyboard sequences, improves Windows modal targeting and text editing, and makes macOS menus, dragging, capture, and focus more reliable ([#6891](https://github.com/agentscope-ai/QwenPaw/pull/6891), [#6913](https://github.com/agentscope-ai/QwenPaw/pull/6913), [#6977](https://github.com/agentscope-ai/QwenPaw/pull/6977))

**Context, Recovery & Long-running Work**

- Snapshot and restore conversations, memory, and selected workspace files without changing project Git history ([#6269](https://github.com/agentscope-ai/QwenPaw/pull/6269))
- Long conversations retain the active task while older exact history moves into a searchable index ([#6323](https://github.com/agentscope-ai/QwenPaw/pull/6323))
- History search returns paired requests and responses and understands date-based queries ([#6237](https://github.com/agentscope-ai/QwenPaw/pull/6237))
- Visual Compact reduces long-context input for supported multimodal models while keeping source recovery ([#6456](https://github.com/agentscope-ai/QwenPaw/pull/6456))
- Long-running tools can continue in the background with progress, extension, and cancellation controls ([#6151](https://github.com/agentscope-ai/QwenPaw/pull/6151))
- Tool workflows can reuse results, branch, loop, and run independent steps in parallel ([#5698](https://github.com/agentscope-ai/QwenPaw/pull/5698))
- ReMe Light memory search can optionally rerank candidates through an OpenAI-compatible endpoint and falls back gracefully when reranking is unavailable ([#6398](https://github.com/agentscope-ai/QwenPaw/pull/6398))
- ReMe Light adds validated, hot-updatable embedding settings, Daily Paper and service-level schedules, per-Agent runtime status, manual reindex controls, and independent search and notification options ([#6772](https://github.com/agentscope-ai/QwenPaw/pull/6772))

**Console & Models**

- Agent Statistics now shows token usage and narrows results to the current Agent ([#6503](https://github.com/agentscope-ai/QwenPaw/pull/6503), [#6402](https://github.com/agentscope-ai/QwenPaw/pull/6402), [#6862](https://github.com/agentscope-ai/QwenPaw/pull/6862))
- Project directory selection can include hidden folders when requested ([#6878](https://github.com/agentscope-ai/QwenPaw/pull/6878))
- Code blocks now share a responsive, theme-aware design with syntax highlighting, copy and download actions; LaTeX and Mermaid blocks add localized Preview and Source tabs ([#6911](https://github.com/agentscope-ai/QwenPaw/pull/6911))
- Explore memory relationships in an interactive 3D graph with focus, filtering, and reduced-motion support ([#6922](https://github.com/agentscope-ai/QwenPaw/pull/6922))

**Channels**

- Feishu, QQ, WeCom, Xiaoyi, and Yuanbao can use opt-in custom gateway endpoints for private deployments and local integration testing without changing their defaults ([#6907](https://github.com/agentscope-ai/QwenPaw/pull/6907))
- Saving an enabled built-in channel warns when the same bot identity is already used by another running Agent, while still allowing an explicit override ([#6909](https://github.com/agentscope-ai/QwenPaw/pull/6909))

- Loop limits are written back for older configurations, and renamed per-tool entries persist ([#6530](https://github.com/agentscope-ai/QwenPaw/pull/6530), [#6682](https://github.com/agentscope-ai/QwenPaw/pull/6682))
- Shell execution preserves multiline commands and no longer hangs on inherited background pipes ([#6412](https://github.com/agentscope-ai/QwenPaw/pull/6412), [#6748](https://github.com/agentscope-ai/QwenPaw/pull/6748))
- Headless tasks construct the effective user message, and workspace commits use a local default Git identity when none is configured ([#6616](https://github.com/agentscope-ai/QwenPaw/pull/6616), [#6350](https://github.com/agentscope-ai/QwenPaw/pull/6350))

- Continuation summaries respect disabled thinking and preserve interruption or timeout behavior ([#6818](https://github.com/agentscope-ai/QwenPaw/pull/6818))
- Headless ACP sessions honor temporary model context and output limits without saving them ([#6933](https://github.com/agentscope-ai/QwenPaw/pull/6933))
