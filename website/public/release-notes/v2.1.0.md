## ✨ Added

**QwenPaw OS Shell**

**QwenPaw Creator**

- Turn an idea or existing footage into a finished video with a team of specialized Agents ([#6284](https://github.com/agentscope-ai/QwenPaw/pull/6284))
- Select clips, subtitles, effects, assets, or text for focused Agent edits while keeping direct controls ([#6740](https://github.com/agentscope-ai/QwenPaw/pull/6740))

- Add project checkpoints, import/export, media recovery, and final review; rendering now validates inputs and reports failures ([#6556](https://github.com/agentscope-ai/QwenPaw/pull/6556), [#6641](https://github.com/agentscope-ai/QwenPaw/pull/6641))
- Add a settings center, external Agent Skill packs, upgraded compose and DAG orchestration, more media renderers, asynchronous image generation, footage observation tools, and cross-platform hardening ([#6870](https://github.com/agentscope-ai/QwenPaw/pull/6870))

**Cross-harness Integration**

- Create Agents powered by Codex or Qoder, with per-session models, permissions, Skills, and MCP services ([#6397](https://github.com/agentscope-ai/QwenPaw/pull/6397))

**Browser-use**

**Computer-use**

- Native Computer-use adds bounded keyboard sequences, safer targeting for Windows modals, and more reliable macOS capture, focus, and text input ([#6891](https://github.com/agentscope-ai/QwenPaw/pull/6891))

**Context, Recovery & Long-running Work**

- Snapshot and restore conversations, memory, and selected workspace files without changing project Git history ([#6269](https://github.com/agentscope-ai/QwenPaw/pull/6269))

- Long-running tools can continue in the background with progress, extension, and cancellation controls ([#6151](https://github.com/agentscope-ai/QwenPaw/pull/6151))
- Tool workflows can reuse results, branch, loop, and run independent steps in parallel ([#5698](https://github.com/agentscope-ai/QwenPaw/pull/5698))
- ReMe Light memory search can optionally rerank candidates through an OpenAI-compatible endpoint and falls back gracefully when reranking is unavailable ([#6398](https://github.com/agentscope-ai/QwenPaw/pull/6398))
- ReMe Light adds validated, hot-updatable embedding settings, Daily Paper and service-level schedules, per-Agent runtime status, manual reindex controls, and independent search and notification options ([#6772](https://github.com/agentscope-ai/QwenPaw/pull/6772))

**Console & Models**
