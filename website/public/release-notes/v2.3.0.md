- Add an unread-only filter to Inbox push messages so older unread messages are easier to find ([#8484](https://github.com/agentscope-ai/QwenPaw/pull/8484))

**Agent Modes**

- Add Advisor Mode: pair an advisor model with a worker model, prepare an opening plan, consult the advisor when needed, and adjust the plan after repeated tool failures ([#7569](https://github.com/agentscope-ai/QwenPaw/pull/7569))
- Add experimental Python Code Mode to combine enabled tools in one script, including concurrent calls and ordered text and media output. Native tool permissions still apply; Code Mode does not enable the sandbox, which is off by default ([#8224](https://github.com/agentscope-ai/QwenPaw/pull/8224))
- Select an initial Agent mode for new ACP sessions with `qwenpaw acp --agent-mode` ([#8352](https://github.com/agentscope-ai/QwenPaw/pull/8352))

**Memory**

- Upgrade ReMe to 0.4.2.0 with image memory, automatic tags, tag-filtered search, and decision-model context compaction that retains references to original tool output. - Browse ReMe Light memory files through clickable tags and a Tags tab, with file counts, pagination, and preserved unsaved edits when opening the same file from different views ([#8470](https://github.com/agentscope-ai/QwenPaw/pull/8470))

**Models & Approvals**

- Sign in with a ChatGPT subscription on a local installation and select models available to the account without a Platform API key; support account switching and sign-out. Remote and Hub sign-in are not supported ([#8437](https://github.com/agentscope-ai/QwenPaw/pull/8437))
- Configure TypeSafe/JEV decision models separately from chat models and use them for tool approvals. Explicit denials remain enforced; uncertain assessments or service failures require manual approval ([#8205](https://github.com/agentscope-ai/QwenPaw/pull/8205), [#8283](https://github.com/agentscope-ai/QwenPaw/pull/8283), [#8360](https://github.com/agentscope-ai/QwenPaw/pull/8360))

**QwenPaw Creator & Data**

- Upgrade Creator to 2.0.3 with custom Skill management and import, direct script import at project creation, narration overlap prevention, temporary-file cleanup, and better handling of models that reject temperature settings ([#8357](https://github.com/agentscope-ai/QwenPaw/pull/8357))
- Update the Data app to 1.0.3 with runtime 0.3.3: inherit the workspace model, retain dataset selections per chat, and keep analysis streams open until completion. The published app manifest still targets QwenPaw 2.2.2 and does not declare 2.3.0 compatibility; older unscoped sessions remain on disk but do not appear automatically in the new listing ([9af3b184](https://github.com/agentscope-ai/QwenPaw/commit/9af3b184), [#8346](https://github.com/agentscope-ai/QwenPaw/pull/8346))

**Skills & Web Search**

- Add Firecrawl as a web search provider with an optional API key ([#8200](https://github.com/agentscope-ai/QwenPaw/pull/8200))
- Configure an optional Tavily API key in the Console, with keyless fallback for rejected keys or quota and rate limits ([#8204](https://github.com/agentscope-ai/QwenPaw/pull/8204))

**Evaluation**
