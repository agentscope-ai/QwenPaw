# Chrome 浏览器扩展

Chrome 扩展把 QwenPaw 连接到你自己的 Chrome。连接之后，Agent 可以在你已经登录的浏览器里开标签页、点击和填写，你能全程看见它在做什么，也可以随时接手。

> **Beta 功能**：目前只支持本地安装（在 Chrome 里加载未打包的扩展程序）。Chrome Web Store 版本尚未发布。

---

## 使用前准备

### 支持的环境

| 项目     | 要求                                                                                |
| -------- | ----------------------------------------------------------------------------------- |
| 浏览器   | 桌面版 Google Chrome                                                                |
| 操作系统 | Windows、macOS、Linux                                                               |
| QwenPaw  | 与 Chrome 在同一台机器上运行，且服务监听本机地址（`127.0.0.1`、`localhost`、`::1`） |

Chrome 扩展依赖 Chrome 的 Native Messaging：扩展需要能启动本机上的 QwenPaw 连接助手。因此以下情况不适用：

- QwenPaw 运行在 Docker、远端服务器或云端环境，而 Chrome 在你本地；
- 通过非本机地址访问控制台（此时安装会明确报错，提示 QwenPaw 需要监听本机地址）。

这些场景请改用独立浏览器（`avatar` / `guest` 身份），详见 [浏览器](./browser)。

### 安装 Chrome 插件

Chrome 连接能力由官方 **Chrome** 插件提供，需要先安装插件：

1. 打开控制台，进入 **设置 → 插件管理**；
2. 在 **官方插件** 中找到 **Chrome**，点击 **安装**；
3. 如果你从其他渠道获得了可信的插件 ZIP 文件或安装地址，点击右上角 **安装插件** 后上传 ZIP，或填写插件 URL；
4. 安装完成后刷新页面，左侧栏会出现 **Chrome浏览器** 入口。

> 请仅安装来自官方插件列表或其他可信来源的插件。该插件会在你的浏览器中代你操作页面，不要为来历不明的 ZIP 文件授予这项能力。

## 安装扩展

打开左侧栏的 **Chrome浏览器**。页面顶部是当前连接状态，下面是 **安装方式**：**本地安装** 标记为 **推荐**，是当前唯一可用的方式；**Chrome Web Store** 显示 **Coming soon**。

按 **本地安装步骤** 操作，只需要完成一次：

1. **复制扩展页地址** — 点击 **复制 chrome://extensions**，在 Chrome 地址栏粘贴并按 Enter；
2. **开启开发者模式** — 在页面右上角打开 **开发者模式** 开关；
3. **点击加载按钮** — 点击 Chrome 页面里的 **加载未打包的扩展程序**；
4. **粘贴路径并打开** — 按右侧 **快捷粘贴路径 Tips**，先点 **复制 QwenPaw 扩展路径**，再按你的系统操作：

| 系统    | 在选择目录的窗口中                                                |
| ------- | ----------------------------------------------------------------- |
| macOS   | 按 `Cmd + Shift + G`，粘贴路径并回车，确认定位到目录后点 **打开** |
| Windows | 点击地址栏，粘贴路径并回车，确认定位到目录后点 **选择文件夹**     |
| Linux   | 按 `Ctrl + L`，粘贴路径并回车，确认定位到目录后点 **打开**        |

完成后回到 QwenPaw 页面，点 **我已安装，刷新状态**。

> 扩展目录也可以用 **复制路径** 或 **打开目录** 直接取用。

## 连接状态

页面顶部会显示三种状态之一：

| 状态                             | 含义                                 | 你要做的                                    |
| -------------------------------- | ------------------------------------ | ------------------------------------------- |
| **安装 Chrome 扩展**             | 扩展文件已就绪，但 Chrome 里还没加载 | 按上面的步骤加载扩展                        |
| **扩展已安装，等待 Chrome 连接** | 扩展已加载，连接尚未建立             | 保持 Chrome 运行，稍等片刻后点 **刷新状态** |
| **Chrome 已连接**                | 连接正常，同时显示扩展版本与连接时间 | 可以让 Agent 使用了                         |

连接建立后，Chrome 工具栏上的 QwenPaw 图标也能查看状态：点开会显示 **Status**（是否已连接）、**QwenPaw tabs**（QwenPaw 正在管理的标签页数量）和扩展 **Version**。

### 连接检查

**连接检查** 区域逐项列出健康状况，每项显示 **就绪** 或 **需要处理**：

| 检查项                    | 含义                                           | 需要处理时的建议                                   |
| ------------------------- | ---------------------------------------------- | -------------------------------------------------- |
| **扩展桥接**              | 扩展与 QwenPaw 之间的连接                      | 重新加载扩展，或重新打开目标浏览器标签页           |
| **Native Messaging 宿主** | 本机连接助手是否已安装且可用                   | 重新安装 Native Messaging 宿主（回到本页重新安装） |
| **扩展资产**              | Chrome 中加载的扩展版本是否与 QwenPaw 自带一致 | 在 `chrome://extensions` 重新加载未打包的扩展      |
| **桥接生命周期**          | 连接是否稳定                                   | 稍候片刻或重启 Chrome                              |

升级 QwenPaw 之后建议回到这个页面看一眼：如果 **扩展资产** 提示版本不一致，重新安装一次并在 Chrome 里重新加载扩展即可。

## 让 Agent 使用你的 Chrome

连接成功后不需要额外配置：`browser.identity` 保持默认的 `auto` 时，Agent 会自动使用你的 Chrome（`user` 身份）。想固定行为可以显式设置，详见 [浏览器](./browser)。

Agent 会在你的 Chrome 里新开标签页工作。遇到登录、验证码、二次验证等必须由人完成的步骤，它会停下来把这一步交还给你。

## 安全边界

- **连接端点不接受手动指定**：它由 QwenPaw 实际监听的地址推导，且必须是本机地址；
- **本地设置文件含一个本机随机生成的连接令牌**，仅当前用户可读（在 macOS / Linux 上以 `600` 权限写入）。扩展只能连接本机的 QwenPaw；
- **扩展只接受来自本机地址的页面通信**（`localhost`、`127.0.0.1`、`[::1]`）。

扩展需要 Chrome 的调试、标签页与全站访问权限才能代你操作页面，这意味着它能操作你在这个 Chrome 里已有的登录态。请只在你愿意让 Agent 代劳的场景下保持连接；不需要时在 `chrome://extensions` 停用扩展即可立即断开。

## 常见问题

### 一直停在"扩展已安装，等待 Chrome 连接"

依次确认：Chrome 正在运行；`chrome://extensions` 里 QwenPaw 扩展处于启用状态；QwenPaw 服务正在运行且监听本机地址。然后点 **刷新状态**。仍未连接时，在 `chrome://extensions` 重新加载扩展。

### 换了服务端口之后连不上

连接端点是按服务实际监听地址推导的。修改 `qwenpaw app` 的端口后，回到本页重新安装一次，然后在 Chrome 里重新加载扩展。

### 重启 Chrome 或电脑休眠后短暂断开

扩展会自动重连（首次约 5 秒，退避最长到 60 秒）。如果断开超过约 1 分钟，扩展会主动停止代 QwenPaw 操作，避免在失联状态下继续动你的页面；重新连上后即可继续。

### 一台电脑上能连多个 QwenPaw 吗

不能。本机连接配置只指向一个 QwenPaw 服务，同一个 Chrome 同时只会连接其中一个。

### Chrome Web Store 版本什么时候有

尚未发布。当前请使用本地安装。

### 我用的不是 Chrome

该扩展目前只支持桌面版 Google Chrome。其他浏览器请使用独立浏览器方式，详见 [浏览器](./browser)。
