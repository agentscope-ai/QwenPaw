# 手机 Web App

> 本地 QwenPaw 和 Platform 都需要支持 Web App。

你可以在手机浏览器中使用 QwenPaw，也可以把它添加到桌面，方便下次打开。通过同一个工作区菜单，就能切换云端部署和已绑定的本地实例，无需从应用商店安装原生 App。添加桌面的方式因系统和浏览器而异。

打开 [platform.agentscope.io/m](https://platform.agentscope.io/m) 即可使用。要接入本地实例，请先按下面的步骤绑定。如果 Platform 尚未支持 Web App，只升级本地 Console 还无法启用此功能。

## 先在电脑上绑定

1. 启动本地 QwenPaw，打开 Console。
2. 点击右上角的手机图标。如果尚未绑定云账号，在弹窗中选择**登录云账号**，并在新窗口完成登录和授权。
3. 连接成功后，原弹窗会显示二维码。你也可以从左下角的工作区菜单登录和管理云账号。

独立运行 QwenPaw 时，直接登录 Platform 即可，无需额外创建本地账号。使用 Hub 时，先登录自己的本地账号，再绑定云账号，账号面板会分别显示两种身份。每次绑定只连接该用户自己的 Runtime，管理员也不例外。

在节点配额允许的范围内，一个云账号可以绑定多个本地账号或设备，每个绑定都有独立凭据。新绑定失败不会影响已有连接；解决面板中提示的配额或网络问题后，点击**重试绑定**即可。

## 扫码登录手机

1. 点击 Console 右上角的**添加到手机**图标。
2. 用手机扫描二维码。如果链接在其他 App 内打开，按指引切换到 Safari（iOS）或系统浏览器，也可以复制完整链接过去。请先切换浏览器，再继续登录。
3. 点击**继续登录**，确认电脑和手机显示的数字一致。
4. 在电脑上点击**确认这台手机登录**。
5. 手机上显示工作区后，按照页面提示添加到桌面。

**扫码会让手机登录完整 Platform 账号**，可以访问这个账号下的全部云端和已绑定工作区。请只确认自己信任的手机。二维码使用有效期为 2 分钟的一次性授权，不包含长期登录令牌。关闭电脑端的二维码弹窗，会取消尚未完成的授权。

如果手机已登录的账号有权访问所扫码的工作区，会直接打开该工作区。切换到其他账号时，仍需在电脑上核对并确认。

## 添加到桌面

| 系统         | 操作                                                                                                                  |
| ------------ | --------------------------------------------------------------------------------------------------------------------- |
| iOS / iPadOS | 在 Safari 中按需打开 **⋯** 菜单，再选择**分享 → 添加到主屏幕 → 添加**。找不到选项时，查看分享面板底部的**编辑操作**。 |
| Android      | 点击**添加到桌面**，浏览器支持时可直接确认安装；也可以从浏览器菜单选择**安装应用 / 添加到主屏幕**。                   |
| HarmonyOS    | 在系统浏览器菜单中查找**添加到桌面**。具体取决于系统和浏览器版本，不支持时可使用书签。                                |

无需安装安卓快应用或鸿蒙原生安装包。请使用带有受信任证书的 HTTPS 地址。微信、钉钉等内置浏览器会先提示在系统浏览器中打开，扫码页也支持复制完整链接。切换浏览器不会提前使用扫码授权；如果授权已过期，或你已经开始登录，请在电脑上刷新二维码后重新扫描。

添加后的桌面图标是 QwenPaw Logo。浏览器登录状态能否带入独立 Web App，取决于系统和浏览器版本。如果打开后仍要求登录，请保持 Web App 打开，再从 Console 重新扫码。

## 工作区与对话

- 从顶部或左下角设置菜单打开工作区列表，选择**云端**或**已绑定**的实例，再选择智能体和对话。
- 页面卡住时可以点击**刷新工作区**，账号和当前工作区会保留。
- 模型、思考强度和模式都在聊天输入框中设置；思考强度能否调节，取决于所选模型是否支持。
- 手机使用所选节点自带的 Console。其他页面、附件、文件工作台和终端沿用该节点的配置与权限。
- 切换工作区时，对话和审批各自独立，不会串到其他节点。
- 本地电脑需要保持开机，QwenPaw 需要持续运行并连接 Platform；手机可以使用不同的网络。
- 断网重连或从后台返回时，页面会恢复已保存的对话状态，不会重复发送上一条消息。
- 节点离线时也可以将它添加到手机，但需要等节点上线后才能使用，不支持离线执行。
- 节点升级后，等待当前回复结束，再点击**更新**以加载新版 Console。未发送的草稿会保留，已发送的请求不会自动重发。

每个支持 Web App 的节点都会加载自带的 Console。终端沿用节点的认证与依赖要求。上传上限为 8 MiB，暂不支持推送通知。

## 退出或解除绑定

手机上的**退出 Web App**会结束当前网页会话。在 Console 中**退出云上账号**会结束电脑端的云登录，但保留节点绑定。Platform 主站有独立的退出入口。

要停止远程访问某个本地节点，在 Console 账号面板中选择**解除绑定**即可，不影响同一云账号下的其他设备。禁用 Hub 用户或更改 Runtime 归属后，该用户原有连接的远程访问也会停止。

## 常见问题

**二维码过期或已使用：** 在电脑上刷新二维码，重新扫码并确认。

**账号已登录，但节点未绑定：** 解决账号面板中提示的配额或网络问题后，重试绑定。

**添加到桌面后要求重新登录：** 浏览器登录状态可能没有带入独立 Web App。打开 Web App，再从 Console 扫描新的二维码即可。不要把长期令牌复制到网址中。

**没有安装按钮：** 按上表通过浏览器菜单添加。网页无法保证浏览器一定显示安装提示。

**Console 无法加载：** 点击恢复页面的**刷新**，也可以切换其他工作区。已经打开的 Console 页面出错时，可点击顶部的**刷新工作区**。刷新不会重新发送上一条消息。
