# 手机 Web App（Beta）

> Beta 功能，可能不稳定。需要本地 QwenPaw 和 Platform 均部署支持此功能的版本。

QwenPaw 手机入口是通过浏览器使用的 Web App。添加到桌面后，可以在 Platform 中切换云端工作区和已绑定的本地 QwenPaw。网页分发无需经过 App Store 或安卓应用商店上架；各系统的桌面入口和安装体验不同。

统一入口：[platform.agentscope.io/m](https://platform.agentscope.io/m)。本 Beta 需要配套部署，不能仅升级本地 Console。

## 先在电脑上绑定

1. 启动本地 QwenPaw，打开 Console。
2. 点击右上角手机图标，在当前弹窗选择 **登录云账号**，并在新窗口完成登录和授权。
3. 授权绑定完成后，原弹窗自动显示二维码。也可从左下角工作区菜单登录和管理云账号。

非 Hub 用户直接登录 Platform，不需要为此创建本地账号。Hub 用户先使用自己的本地账号登录，再绑定云上账号；账号面板会分别显示两种身份。每个 Hub 用户绑定的是自己的个人 Runtime，管理员的身份不会扩大远程访问范围。

一个云账号可以关联多个本地账号或设备，各绑定分别保存凭据，并遵守 Platform 的节点配额。配额不足时，已有绑定保持不变，可在问题解决后点击 **重试绑定**。

## 扫码登录手机

![Console 中的 Platform 账号入口](/images/mobile/console-account.jpg)

1. 点击 Console 右上角的手机图标 **添加到手机（Beta）**。
2. 用手机任意扫码工具扫描二维码；若页面提示在浏览器中打开，按指引切换到 Safari（iOS）或系统浏览器，也可复制完整链接过去。请先切换浏览器，再继续登录。
3. 点击 **继续登录**，核对电脑和手机显示的数字。
4. 在电脑上点击 **确认这台手机登录**。
5. 手机上显示工作区后，按照页面提示添加到桌面。

**扫码授权会登录完整 Platform 账号**，可访问该账号下的全部云端和绑定目标。仅在你信任的手机上确认。二维码不包含长期登录令牌；它使用有效期 2 分钟、只能兑换一次的授权。关闭电脑端二维码面板会取消尚未完成的授权。

手机已经登录同一个账号并有权访问扫码目标时，会直接进入该目标。扫描其他账号的二维码时，仍需经过电脑核对确认，才能切换登录身份。

## 添加到桌面

| 系统         | 操作                                                                                            |
| ------------ | ----------------------------------------------------------------------------------------------- |
| iOS / iPadOS | 在 Safari 中打开，点击 **分享 → 添加到主屏幕 → 添加**。网页只能提供引导，不能自动代替系统操作。 |
| Android      | 浏览器支持时点击网页上的 **安装**；否则在浏览器菜单中查找 **安装应用 / 添加到主屏幕**。         |
| HarmonyOS    | 在系统浏览器菜单中查找 **添加到桌面**；实际能力取决于系统和浏览器版本，不支持时可以使用书签。   |

无需安装安卓快应用或鸿蒙原生安装包。使用受信任的 HTTPS 地址。微信、钉钉等应用内置浏览器会先显示外部打开指引，扫码页也始终提供浏览器打开帮助和复制完整链接。切换浏览器不会提前消费扫码授权；若二维码已过期或已开始授权，请在电脑上刷新后重扫。安装图标使用 QwenPaw Logo。支持安装时 Cookie 衔接的系统可以恢复登录；若独立启动后要求登录，请回电脑重新扫码。

## 使用与恢复

![手机端沿用 Console 的模型与思考强度控件（演示环境）](/images/mobile/model-thinking.jpg)

- 点击顶部的实验图标打开工作区菜单，切换 **云端** 和 **已绑定** 目标，再选择智能体和对话。
- 手机直接复用所选节点同版本的 Console。模型、思考强度和模式在聊天输入框的原有控件中设置；页面、附件、文件工作台及终端也沿用 Console，实际能力取决于节点配置。
- 切换工作区会清空当前界面的目标上下文，不把另一节点的消息或审批带入新目标。
- 本地电脑必须保持开机，QwenPaw 必须运行，并能主动连接 Platform。无需手机和电脑在同一局域网。
- 断网或切后台后，恢复页面会读取保存的对话状态；不会自动重发上一条用户消息。
- 节点离线时可以完成手机接入，恢复在线后才能操作该节点。Web App 不提供离线执行。
- 节点升级后会提示更新 Console；等待当前回复结束，再点击 **更新**。未发送草稿保留，已发送请求不会自动重发。

旧到不支持 Web App 的节点需要先升级。网页入口更新不要求所有节点同时升级，但接入协议必须受支持。终端沿用节点本身的认证与依赖要求；HTTP 上传上限为 8 MiB。暂不提供推送通知或离线执行，安装、语音权限和后台行为仍需按具体机型验证。

## 退出和解绑

手机账号菜单中的 **退出 Web App** 结束当前手机网页会话。Console 中 **退出云上账号** 结束电脑端的云登录；节点绑定单独保留。Platform 主站遵循其原有账号会话，可在主站单独退出。

要停止远程访问当前本地节点，在 Console 账号面板中选择 **解除绑定**。此操作只撤销当前绑定，不影响同一云账号下的其他设备。Hub 用户禁用或 Runtime 归属变化时，原用户的本地映射也会停止转发。

## 常见问题

**二维码过期或已使用：** 在电脑上刷新二维码，重新扫码并确认。

**账号已登录但节点未绑定：** 查看面板中的错误信息，解决配额或网络问题后重试绑定。

**添加后要求重新登录：** 浏览器与独立 Web App 的会话衔接取决于系统版本。重新扫码即可，勿复制长期令牌到网址中。

**没有安装按钮：** 使用上表中的浏览器菜单步骤。网页不保证能自动弹出系统安装对话框。
