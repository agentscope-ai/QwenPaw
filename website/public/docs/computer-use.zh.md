# 电脑操作（Computer Use）

Computer Use 是一个可选的工具插件，让 QwenPaw 的 Agent 在你的电脑上操作**已经授权的桌面应用**。它可以打开应用、查看窗口内容、点击按钮、输入文字、滚动或拖动，用来完成重复的桌面操作。

> **Beta 功能**：Computer Use 目前支持 Windows 和 macOS，且仅在 QwenPaw Desktop 桌面应用中可用。使用前需要先安装插件。请在你能够查看操作过程、并愿意授予目标应用访问权限时使用。

---

## 使用前准备

### 支持的平台

Computer Use 依赖 QwenPaw Desktop 提供的本机能力。目前支持：

| 平台    | 要求                                                 |
| ------- | ---------------------------------------------------- |
| Windows | Windows 10 或更高版本，x64 架构                      |
| macOS   | macOS 14（Sonoma）或更高版本；推荐 Apple Silicon Mac |

Linux、浏览器版控制台、Docker 和纯命令行环境暂不支持 Computer Use。当前插件版本适配 QwenPaw 2.1.x；安装时请以插件管理页显示的兼容性提示为准。

### 安装 Computer Use 插件

Computer Use 不是默认启用的内置工具，需要先安装插件：

1. 启动 QwenPaw Desktop，进入 **设置 → 插件管理**；
2. 在 **官方插件** 或 **插件市场** 中搜索 **Computer Use**，点击 **安装**；
3. 如果你从其他渠道获得了可信的插件 ZIP 文件或安装地址，点击右上角 **安装插件** 后上传 ZIP，或填写插件 URL；
4. 安装完成后，在“已安装插件”中确认 **Computer Use** 状态为“运行中”；若仍未加载，请重启 QwenPaw Desktop。

> 请仅安装来自官方插件列表、插件市场或其他可信来源的插件。不要为来历不明的 ZIP 文件授予桌面自动化权限。

### 使用 QwenPaw Desktop

Computer Use 依赖桌面应用提供的本机能力。请先安装并启动 [QwenPaw Desktop](./desktop)，再按上面的步骤安装插件。

### macOS：允许所需权限

首次使用时，macOS 可能会请求以下权限：

- **辅助功能**：让 QwenPaw 可以操作已授权应用中的控件；
- **屏幕录制**：让 QwenPaw 可以读取目标窗口的画面。

请按系统提示允许。如果没有看到提示，或授权后仍无法操作，请前往 **系统设置 → 隐私与安全性**，确认 QwenPaw Desktop 已在“辅助功能”和“屏幕录制”中获准访问，然后重新启动 QwenPaw Desktop。

Windows 通常不需要额外设置；系统安全弹窗和需要管理员权限的界面不会作为操作目标。

## 功能开关

Computer Use 有全局和 Agent 两级开关。只有两者都开启时，Agent 才能使用该功能；操作某个应用时，仍需单独确认该应用的访问授权。

| 开关             | 位置                             | 作用范围                                       |
| ---------------- | -------------------------------- | ---------------------------------------------- |
| **全局开关**     | **电脑操作 → 启用电脑操作**      | 当前 QwenPaw Desktop 安装中的所有 Agent 和对话 |
| **Agent 级开关** | **智能体 → 工具 → Computer Use** | 当前选中的 Agent                               |

### 全局开关

在 QwenPaw Desktop 左侧菜单中打开 **电脑操作**，确认运行环境显示“已就绪”，并检查 **启用电脑操作** 是否开启。首次安装且尚未保存过选择时，该开关默认开启；你的选择会在重启桌面应用后保留。

如果左侧没有“电脑操作”，请先确认插件已经安装并重新启动桌面应用。

关闭全局开关后，所有 Agent 和对话都不能再使用 Computer Use，同时会停止正在进行的自动化并取消等待中的应用授权。它适合暂时关闭整个功能，不用于停止某一段对话。

### Agent 级开关

进入需要使用该功能的 Agent 的 **智能体 → 工具** 页面，确认 **Computer Use** 已开启。插件会为 Agent 添加这个工具，并保留你已经保存的开关选择。

关闭 Agent 级开关只会禁止当前 Agent 使用 Computer Use，不会影响其他 Agent，也不会关闭全局开关。它不是中止当前任务的开关；要停止某个对话中的任务，请直接停止该对话。

## 3 步开始使用

### 1. 在对话中启动 Computer Use

在需要操作桌面应用的聊天中输入 **`/computer_use`**，按提示启动 Computer Use，再继续描述要完成的任务。

开始前请确认上面的全局开关和当前 Agent 的工具开关都已开启。

### 2. 把任务交给 Agent

直接说明你想完成的事情和目标应用。例如：**`/computer_use 在记事本里新建一份会议记录，写入下面三条待办事项。`**

首次操作某个应用时，Agent 会先查看可用窗口，再读取目标窗口的当前状态，然后才执行点击或输入。界面发生变化后，它也会再次确认窗口状态。

### 3. 确认应用授权

当 Agent 需要操作一个新应用时，聊天中会出现**应用访问请求**。请核对应用名称和显示出的文件路径，再选择：

| 选项               | 含义                                                |
| ------------------ | --------------------------------------------------- |
| **拒绝**           | 不允许 Agent 操作这个应用，本次任务不会继续操作它。 |
| **仅本次会话允许** | 只在当前聊天会话中允许，结束会话后需要再次确认。    |
| **始终允许**       | 保存该应用的授权，之后操作同一应用不再重复询问。    |

不确定时，请优先选择“仅本次会话允许”。

## 暂停、继续与停止

### 临时自己操作电脑

如果你刚使用过鼠标或键盘，Computer Use 会暂时拒绝 Agent 的下一次桌面操作，避免它与你同时操作同一个界面。此时请稍等片刻，再让 Agent 重新确认窗口状态后继续。

这项保护不会自动关闭整个任务，也不会替你保存或撤销应用中的改动。

### 立即停止

若要停止当前对话中的电脑操作，直接停止该对话即可；该对话中的 Agent 和电脑操作都会随之中断。

### 管理长期授权

在 **电脑操作 → 授权管理** 中可以查看所有“始终允许”的应用，并随时撤销某一项授权。撤销后，下次操作该应用时会再次请求你的确认。

## 安全边界

Computer Use 会将输入绑定到刚才观察过的目标窗口，并在桌面锁定或检测到你刚使用过鼠标、键盘时拒绝新的桌面输入。原生运行时也会拒绝操作 QwenPaw 自身窗口，以及能够被系统识别的部分凭证窗口。

这些保护并不能识别所有敏感界面。系统权限或安全提示、密码和验证码输入框、人机验证及双重验证等场景，主要依赖 Agent 的操作指引，不应视为功能层面的绝对拦截。

遇到上述敏感界面时，请自行完成操作，或在继续前仔细确认。请只向你信任的 Agent 授予你信任的应用访问权限；对于“始终允许”，尤其要核对应用路径，避免授权给名称相似但来源不明的程序。

## 常见问题

### 显示“运行环境不可用”怎么办？

确认你正在使用 QwenPaw Desktop，而不是浏览器版控制台或命令行版本。重启桌面应用后仍不可用时，请更新到包含 Computer Use 的最新版本，并在问题反馈中附上桌面应用日志。

### macOS 上看不到窗口画面，或 Agent 无法点击怎么办？

检查 **系统设置 → 隐私与安全性** 中 QwenPaw Desktop 的“辅助功能”和“屏幕录制”权限；修改权限后请完全退出并重新打开 QwenPaw Desktop。

### Agent 找不到目标应用怎么办？

先手动打开目标应用，并让它的窗口保持可见，再重新提出任务。如果应用有多个窗口，请说明你希望操作的窗口内容或标题。

### 我刚操作了鼠标，为什么 Agent 没有继续？

这是防止人和 Agent 同时操作桌面的保护。等待片刻后，请让 Agent 重新查看目标窗口再继续；不要让它重复使用刚才的点击位置。
