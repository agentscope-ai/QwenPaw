# 在手机上继续使用你的 QwenPaw：Web App

离开电脑后，也可以拿起手机继续使用本地的 QwenPaw。通过 Web App，你能在浏览器中打开工作区，也能把它添加到手机桌面，在同一个入口切换云端部署和已绑定的本地实例，无需安装原生 App。

本地 QwenPaw 和 Platform 都需要支持 Web App。

## 从 Console 开始

手机入口是 [platform.agentscope.io/m](https://platform.agentscope.io/m)。要接入本地工作区，可以先从电脑上的 Console 开始。

点击本地 Console 右上角的手机图标。如果还没有绑定云账号，直接在弹窗中登录；连接成功后，原弹窗就会显示二维码。用手机扫码，核对两端显示的数字，再在电脑上确认登录。

你可以使用任意扫码工具。如果链接在微信、钉钉等应用内打开，按页面指引切换到 Safari 或系统浏览器，再继续登录；也可以复制完整链接到浏览器中。登录成功后，页面会介绍如何将 QwenPaw 添加到桌面。

扫码登录的是**完整 Platform 账号**，手机可以访问这个账号下的全部云端和已绑定工作区，因此请只确认自己信任的手机。二维码使用短期、一次性授权，不会携带长期账号令牌。

Hub 用户的本地账号和云账号分别显示，每次绑定只连接该用户自己的 Runtime。非 Hub 用户直接登录 Platform 即可，无需额外创建本地账号。在节点配额允许的范围内，一个云账号可以绑定多个本地账号或设备。

## 还是你熟悉的 Console

手机加载的是所选节点自带的 Console。模型、思考强度和模式依然在聊天输入框中设置；思考强度能否调节，取决于所选模型是否支持。切换工作区时，对话和审批各自独立，不会串到其他节点。

每个页面的顶部和左下角设置菜单都可以打开工作区列表，查看云端部署、已绑定电脑及其在线状态。页面卡住时，点击**刷新工作区**即可重新连接，无需重新登录。

切到后台再回来，页面会恢复已保存的对话状态，不会重复发送上一条消息。节点升级后，刷新即可加载更新后的 Console；手机和电脑使用同一套界面。

本地 QwenPaw 仍然运行在你的电脑上，因此电脑需要保持开机、联网。手机通过 Platform 访问它，可以使用不同的网络，也不用手动填写局域网地址。

## 三种系统，共用网页入口

iPhone 和 iPad 按需打开 Safari 的 **⋯** 菜单，再选择**分享 → 添加到主屏幕**。支持安装提示的 Android 浏览器会在点击**添加到桌面**后直接弹出确认，也可以从浏览器菜单添加。HarmonyOS 可在系统浏览器中查找添加到桌面的选项，具体能力取决于系统和浏览器版本。

附件、文件工作台和终端沿用所选节点的配置与权限。Web App 暂不支持推送通知或离线执行。

完整步骤、账号授权范围和常见问题见[手机 Web App 使用指南](/docs/mobile)。
