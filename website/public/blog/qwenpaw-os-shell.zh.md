# QwenPaw OS Shell：把对话、智能体与应用装进一张 AI 桌面

当 Agent 从“回答问题”走向“持续完成工作”，用户面对的就不再只有一个聊天框。

一次完整任务可能同时涉及对话、文件、审批、应用、配置和多个 Agent。传统管理界面通常把这些能力拆散在侧边栏和不同页面里：你需要记住入口，也需要不断切换上下文。

**QwenPaw OS Shell** 提供了另一种组织方式：把 QwenPaw 已有的前端页面装进一张桌面。对话是一个窗口，文件与工具是应用，每个 Agent 拥有独立的智能体空间；你可以像使用桌面操作系统一样打开、排列、最小化和切换它们。

这里的“OS”是一种**前端桌面交互概念**。QwenPaw OS Shell 不是独立操作系统，也不会替代 Windows、macOS 或 Linux。它与经典 QwenPaw Console 共用同一套后端、Agent、配置和应用路由，只是提供了更适合多任务工作的桌面式界面。

## 01 如何进入 QwenPaw OS Shell

进入 QwenPaw OS Shell 不需要输入命令或修改浏览器地址，直接在经典 Console 中切换即可：

1. 在经典 Console 左下角点击**齿轮按钮**，打开快捷设置；
2. 在快捷设置的“模式”区域找到**进入桌面模式**；
3. 点击后，当前页面会直接切换到 QwenPaw OS Shell。

首次使用时，Console 会在左下角显示“试试桌面模式”的引导提示，并指向快捷设置入口。按照提示点击即可找到“进入桌面模式”。

![从经典 Console 的快捷设置进入桌面模式](https://img.alicdn.com/imgextra/i4/O1CN016yb4RooFSZJ5Bsl3_!!6000000006635-0-tps-2557-1224.jpg)

进入后，页面会切换为全屏桌面布局。顶部是菜单栏，中间是应用窗口和桌面图标，底部是程序坞（Dock）。首次进入时可能会短暂显示启动画面。

需要返回经典 Console 时，点击左上角的 **QwenPaw 标识**，再选择“返回控制台”即可。OS Shell 只是另一种前端入口，切换界面不会创建第二套 QwenPaw 数据。

![QwenPaw OS Shell 桌面中的 Chat 窗口](https://img.alicdn.com/imgextra/i1/O1CN01JLELdKorvLB5CGAm_!!6000000004339-0-tps-2560-1228.jpg)

## 02 认识桌面：图标、启动器、程序坞与窗口

进入 OS Shell 后，可以通过三种方式打开应用：

1. **桌面图标**：双击图标打开对应应用；
2. **启动器**：点击程序坞最左侧的网格按钮，查看和打开当前可用的全部应用；
3. **程序坞**：点击已经固定或正在运行的应用图标，打开应用或让已有窗口回到前台。

每个应用都会在独立窗口中运行。窗口顶部显示应用名称，并提供关闭、最小化和最大化按钮：

- **关闭**：结束当前窗口，需要时可以从桌面、启动器或程序坞重新打开；
- **最小化**：暂时收起窗口，应用仍保留在当前智能体空间中；
- **最大化**：让窗口占满主要工作区域，再次点击即可恢复原来的尺寸；
- **切换焦点**：直接点击任意窗口，或点击程序坞中的运行中应用；
- **调整位置与大小**：拖动标题栏移动窗口，拖动边缘或四角改变尺寸。

双击窗口标题栏也可以在最大化和原始尺寸之间切换。桌面上的应用图标可以拖动整理，程序坞中的应用也可以按自己的工作习惯固定和排序。

这套操作方式不会改变应用本身的功能。Chat、Files、Skills、配置页和 PawApp 仍然使用 QwenPaw 原有页面，只是被 OS Shell 放进了统一的窗口系统中。

## 03 在对话中发起任务，并在关键动作前审批

Chat 是 QwenPaw OS Shell 中最直接的任务入口。打开 Chat 后，可以像平常一样描述目标，让当前 Agent 分析问题、使用工具并持续反馈进度。

对话并不意味着把所有权限一次性交给 Agent。当工具调用触发安全策略时，QwenPaw 会暂停对应动作并等待人工决定。

你可以通过三种方式处理审批：

1. 在桌面右上角的审批通知中直接选择“批准”或“拒绝”；
2. 点击通知进入 Inbox，查看更完整的工具、参数与风险信息后再决定；
3. 在 Chat 中输入 **`/approve`** 或 **`/deny`**，处理当前待审批请求；存在多个请求时，也可以带上 request ID。

审批只控制待执行的关键动作，不会关闭当前对话。批准后任务继续推进；拒绝后 Agent 会收到结果，并可以调整方案或向你解释下一步。

**建议：** 不要只看“Agent 想继续工作”，还要核对它准备调用的工具、目标路径和影响范围。信息不完整时，先拒绝并要求 Agent 说明理由，通常比直接放行更稳妥。

## 04 切换智能体，也切换整套工作现场

在 QwenPaw OS Shell 中，每个 Agent 都对应一个独立的**智能体空间（Agent Space）**。空间会保存该 Agent 当前打开的窗口和桌面布局，因此切换 Agent 不只是切换一个名称，而是切换整套工作现场。

把鼠标移到桌面顶部，呼出智能体空间条，再直接点击空间名称切换。每个空间会显示当前保存的窗口数量，方便你选择要继续的工作现场。

例如，你可以把 Default Agent 用于日常对话，把 QA Agent 用于产品问答或文档核验。进入 QA Agent 的空间后，它拥有自己的窗口组合，不会把 Default Agent 的桌面挤乱。

![QA Agent 的独立桌面空间](https://img.alicdn.com/imgextra/i4/O1CN015P4tmnPeQSG5CGAn_!!6000000002843-0-tps-2560-1229.jpg)

这种隔离方式适合两类场景：一类是按角色分工，例如“研究”“开发”“质检”；另一类是按项目分工，让不同 Agent 的对话、文件和应用窗口保持清晰边界。

需要注意的是，智能体空间隔离的是 OS Shell 中的窗口现场。切换空间时，当前窗口布局会被保留；再次切回时，可以继续从原来的窗口组合开始工作。

## 05 从应用市场安装应用，安装后立即打开

QwenPaw OS Shell 提供了统一的**应用市场**，用于管理桌面应用和 PawApp。应用市场中的内容主要分为三类：

- QwenPaw 内置的桌面应用；
- 当前已经安装的 PawApp；
- 来自插件市场、可以继续安装的应用。

![QwenPaw OS Shell 应用市场](https://img.alicdn.com/imgextra/i4/O1CN01HGGw9SrWaUK5CGAi_!!6000000006930-0-tps-2560-1224.jpg)

安装流程与普通桌面应用类似：

1. 双击桌面的“应用市场”；
2. 搜索或浏览目标应用；
3. 检查应用说明、版本和兼容性提示；
4. 点击安装，等待安装完成；
5. 从桌面图标或启动器打开新应用。

在本次走查中，我们安装了 **Agent Kanban**。安装完成后，它立即出现在 QwenPaw OS Shell 桌面，并可以在独立窗口中打开，无需离开当前智能体空间。

![安装后打开的 Agent Kanban](https://img.alicdn.com/imgextra/i4/O1CN01ry1ahIYcqPE5CGAk_!!6000000007395-0-tps-2560-1226.jpg)

应用本质上仍运行在 QwenPaw 的插件与路由体系中，因此安装前应确认来源、版本兼容性和所需权限。对于不再使用的应用，可以回到应用市场卸载。

## 06 在系统设置中统一完成配置

QwenPaw 的能力越多，配置入口越需要集中。系统设置将常用管理能力放在同一个窗口中，包括：

- Agents 与模型；
- Skill Pool 与运行环境；
- Security 与 Token Usage；
- Backups 与 Voice Transcription；
- Debug 与 Plugin Manager。

![QwenPaw OS Shell 系统设置](https://img.alicdn.com/imgextra/i1/O1CN0197z888mPcoD5CGAl_!!6000000001126-0-tps-2560-1227.jpg)

如果要新增 Agent、调整模型、管理 Skills 或检查安全设置，可以双击桌面的“系统设置”，再从左侧选择对应分类。配置完成后关闭窗口即可回到原来的桌面，其他应用的位置不会被打断。

对于准备长期运行的实例，建议优先检查三项配置：默认模型是否可用、Agent 的工具范围是否符合职责、Security 中的审批与沙箱策略是否符合当前工作区的风险级别。

## 07 多窗口协同：把任务上下文留在桌面上

复杂任务往往不适合在一个页面里完成。QwenPaw OS Shell 允许多个应用窗口同时打开，让对话、文件、配置和专业应用留在同一张桌面上。

一个典型的工作组合可以是：

- 在 Chat 中交代任务并持续查看 Agent 的进度；
- 在 Files 中核对 Agent 读取或生成的文件；
- 在 Agent Kanban 等 PawApp 中管理结构化任务；
- 保留系统设置窗口，以便随时调整 Agent、模型或安全配置。

![Chat、Files 与 Agent Kanban 多个窗口同时展开](https://img.alicdn.com/imgextra/i3/O1CN01sEc6VFNbC5J5CGAe_!!6000000000192-0-tps-2560-1220.jpg)

### 排列与切换窗口

拖动窗口标题栏，可以自由调整窗口位置；拖动窗口边缘或四角，可以改变宽度和高度。将窗口拖向桌面边缘时，还可以使用贴靠布局，把两个工作窗口并排放置。

点击窗口会将它带到最前方。窗口较多、彼此遮挡时，可以点击程序坞中的应用图标快速聚焦；运行中的应用会在程序坞中保留状态标记。

### 暂时收起窗口

需要腾出桌面空间时，点击最小化按钮。窗口会被收起，但不会从当前智能体空间中删除。之后点击程序坞中的应用即可恢复窗口，原来的任务上下文仍然保留。

关闭窗口与最小化不同：关闭后窗口会从当前桌面移除，但应用并未卸载，仍可从桌面图标、启动器或应用市场重新打开。

### 用任务总览管理多个窗口

当窗口数量较多时，把鼠标移到桌面顶部，呼出智能体空间条并点击当前空间名称。任务总览会列出当前智能体空间中的全部窗口，点击任意窗口卡片即可直接聚焦该应用。

任务总览顶部还会显示每个智能体空间当前保存的窗口数量。因此它既是窗口切换器，也是不同 Agent 工作现场的总入口。

上图中，Chat、Files 和 Agent Kanban 三个窗口同时展开在 QA Agent 的空间。窗口可以并排，也可以按照使用频率层叠摆放；点击其中任意一个，便可将它带到最前方。你不必为了查看文件而离开对话，也不必在多个独立页面之间来回寻找入口。对需要持续观察和频繁核验的 Agent 工作流而言，让上下文保持可见，往往比单纯增加更多功能更重要。

## 08 使用与安全提示

QwenPaw OS Shell 让 Agent 工作更直观，但窗口化不会改变应用与工具原本拥有的权限。开始使用前，建议保留以下习惯：

1. **先看目标，再批权限。** 审批时核对工具、参数、路径和实际影响，不因通知频繁而机械放行。
2. **按职责划分智能体空间。** 不同项目或信任边界使用不同 Agent，避免敏感工作与日常任务混在同一上下文中。
3. **只安装可信应用。** 优先使用官方列表、插件市场或经过验证的来源，并关注版本兼容性。
4. **让模型、工具和权限相匹配。** 能力更强的 Agent 应配合更明确的工作区边界、沙箱与审批规则。
5. **定期整理窗口与应用。** 关闭不再使用的窗口，卸载不需要的应用，让每个智能体空间保持清晰。

从一个聊天页面到一张 AI 桌面，变化不只是“多了几个窗口”。QwenPaw OS Shell 把 Agent、应用与人的决策放进同一个可见工作现场：Agent 可以持续推进，人仍然能在关键节点理解、切换和接管。

当对话、审批、配置和多个应用都能在桌面上各就各位，QwenPaw 才更接近一个可以长期使用的个人 Agent 工作空间。
