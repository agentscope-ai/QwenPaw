# 超好玩的 QwenPaw 插件推荐①｜开会、排任务、亮灯与画图

如果你对 QwenPaw 的印象还停留在“一个可以聊天的 AI 助手”，那插件广场可能会让你重新认识它。

装上插件之后，QwenPaw 不但能召集多个智能体开会、把讨论结果变成看板任务，还能在调用工具时点亮桌上的环形灯，最后直接生成文章封面和宣传图。它开始从一个聊天窗口，变成一套能协作、执行、感知和创作的智能体工作台。

这是「超好玩的 QwenPaw 插件推荐」第一期。我们选择了四个风格完全不同、但刚好可以组成一条完整工作流的插件：TeamChat、Agent Kanban、AgentAura，以及 OpenRouter 图像生成工具。

> 兼容性说明：截至 2026 年 7 月 23 日，以下版本在插件广场的兼容信息中均包含 QwenPaw 2.0。插件仍会持续更新，安装时请以详情页显示的最新版本为准。

## 01 TeamChat：把多个智能体请进同一间会议室

平时使用多个智能体，最常见的方式是分别和它们对话：让研究智能体找资料，让写作智能体整理文章，再让审校智能体检查内容。问题是，这些讨论彼此割裂，最后仍然需要人来回搬运信息。

TeamChat 提供了一种更有现场感的协作方式：选择一个智能体担任主持人，再邀请其他智能体加入会谈。人类提出议题后，主持人负责拆解问题、协调发言和推进讨论，其他智能体则从不同角度给出意见。

它不只是在一个页面里摆放几个聊天框。插件还提供头脑风暴、多标签并行会话、观点切换与对比、历史会谈、文件收集、PPT 回放和圆桌动画等能力。讨论时间较长时，可以切换到其他标签处理别的事情；会谈结束后，再回来查看完整结果。

例如，我们可以发起一场“QwenPaw 插件推荐文章策划会”：让产品智能体负责选题，内容智能体设计文章结构，技术智能体检查事实，主持人最后汇总出一份可执行方案。原本需要多次复制粘贴的过程，被放进了一场真正的多智能体会议里。

**推荐给谁：** 经常使用多个智能体做内容策划、方案讨论、研究分析或团队决策的人。

**体验建议：** TeamChat 的功能非常丰富，第一次使用时可以先聚焦“选择主持人—邀请智能体—发起讨论—查看观点”这条主流程，邮箱、频道和音乐等扩展能力可以之后再探索。

## 02 Agent Kanban：讨论结束，智能体开始排队干活

一场讨论最怕的不是没有想法，而是想法停在聊天记录里。

Agent Kanban 把 QwenPaw 的智能体协作变成了一块可以拖拽的任务看板。看板包含“待规划、等待调度、进行中、审核中、已完成”五个阶段。你可以创建任务、选择负责的智能体并启动执行，插件会通过实时流式输出展示智能体正在做什么。

它还保留了重要的人机协作环节：当工具调用需要批准时，用户可以在任务过程中进行确认；智能体完成工作后，任务不会悄悄消失，而是进入审核阶段，等待人来检查结果。除了按任务状态查看，还可以切换到 Agent 视图，观察每个智能体分别承担了哪些工作。

如果说 TeamChat 解决的是“大家一起想”，Agent Kanban 解决的就是“想完之后谁来做”。例如，会议确定要发布一篇产品文章后，可以把资料搜集、插件试用、配图生成和终稿检查拆成四张卡片，分别交给不同智能体执行。

**推荐给谁：** 希望把 QwenPaw 用于持续项目、内容生产或多步骤任务，而不只是完成一次性问答的人。

**体验建议：** Agent Kanban 目前仍是较新的 0.1.0 版本，适合尝鲜和展示 QwenPaw 2.0 App 插件的可能性。重要任务仍建议保留人工审核和结果备份。

## 03 AgentAura：AI 在思考，桌上的灯也知道

AgentAura 是本期最有“实体感”的插件。它把 QwenPaw 的运行状态同步到独立桌宠 App 或 ESP32 环形灯板，让智能体的活动不再只存在于屏幕里的小字提示。

当 QwenPaw 启动、收到消息、进入思考、调用工具、等待审批、执行完成或发生错误时，AgentAura 会把这些事件转换成不同的桌宠状态或灯光效果。例如，启动时显示彩虹灯效，忙碌和思考时显示黄色动态灯效，完成后回到蓝色呼吸，出错时则切换为红色闪烁。

这看起来像一个有趣的桌面玩具，却解决了一个真实问题：当智能体执行耗时任务时，我们不必一直盯着聊天窗口。抬头看一眼灯光，就能知道它是在运行、等待确认，还是已经完成。

AgentAura 支持 HTTP、UDP 和 USB 串口三种连接方式。如果没有硬件，也可以先配合独立桌宠 App 体验；如果喜欢动手，再连接 ESP32 和 WS2812B 环形灯板，把它做成真正的桌面智能体状态灯。

**推荐给谁：** 喜欢桌宠、智能硬件、桌搭，或者经常让智能体在后台长时间执行任务的人。

**体验建议：** 这是四个插件中准备工作最多的一个，需要额外安装桌宠 App 或准备兼容硬件。用于公开网络或局域网连接时，也应认真配置访问边界和认证信息。

## 04 OpenRouter 图像生成工具：让 QwenPaw 自己完成配图

讨论有了、任务排好了，接下来还缺一张能用的封面。

OpenRouter 图像生成工具让 QwenPaw 可以直接调用 OpenRouter Image API，在对话中完成图片生成和编辑。它同时支持 Google Gemini 和 OpenAI GPT Image 系列模型，可以根据任务切换不同模型，并处理分辨率、宽高比、画质、透明背景和参考图等参数。

实际使用时，不需要每次手动填写一长串配置。你可以直接告诉 QwenPaw：“生成一张 16:9 的文章封面，主题是四个智能体围绕任务看板协作，画面右侧保留标题区域。”智能体会根据描述组织参数、调用模型，并把生成结果保存下来。需要修改时，也可以继续提供参考图并说明要调整的部分。

对于写博客、做社交媒体内容或产品演示的人来说，它最大的价值不是“又多了一个生图入口”，而是图像生成可以直接接入智能体工作流：Agent Kanban 上的“生成封面”任务，不再需要切换到另一个网站手动完成。

**推荐给谁：** 需要频繁制作文章封面、产品配图、概念图或基于参考图进行修改的内容创作者。

**体验建议：** 使用前需要准备 OpenRouter API Key，不同模型可能产生不同费用；模型名称和可用参数也可能随服务更新，正式使用前建议先用低成本设置完成小图测试。

## 四个插件连起来，才是这一期真正好玩的地方

这四个插件并不是四座互不相关的功能孤岛。把它们组合起来，可以形成一条相当完整的智能体工作流：

1. 在 **TeamChat** 中发起选题会，让多个智能体讨论目标、受众和内容结构。
2. 把确定的工作拆进 **Agent Kanban**，分别交给研究、写作、设计和审校智能体。
3. 执行期间通过 **AgentAura** 的桌宠或灯光了解智能体是在思考、等待审批还是已经完成。
4. 最后用 **OpenRouter 图像生成工具**完成封面和配图，把成果直接交付出来。

这也是 QwenPaw 插件生态最值得探索的地方：一个插件解决一个具体问题，多个插件组合后，则能改变整套工作方式。聊天只是入口，真正有趣的是让智能体开始组织协作、推动任务，并和我们的数字与实体环境发生联系。

如果你刚开始尝试，可以先从 TeamChat 或 Agent Kanban 入手；如果更在意视觉效果，AgentAura 的灯光联动最有惊喜；如果平时就需要大量配图，OpenRouter 图像生成工具会更快体现实际价值。

## 安装与安全提示

- 四个插件均可从 [AgentScope Platform Plugin 广场](https://platform.agentscope.io/plugins)进入详情页查看和安装。
- 截至本文核对日期，四个详情页均显示通过平台安全扫描；安全扫描不等于绝对安全，插件会在 QwenPaw 进程内运行，仍应确认来源和权限。
- 安装前请再次核对详情页中的 QwenPaw 兼容信息、依赖条件和最新版本说明。
- AgentAura 需要桌宠 App 或兼容硬件；OpenRouter 图像生成工具需要单独的 API Key，并可能产生模型调用费用。
