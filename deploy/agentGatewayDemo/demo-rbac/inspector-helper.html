QwenPaw RBAC — 换岗降权演示（网关策略，Token 不变）

Gateway: http://localhost:3000/mcp · 员工 Token 一经发放不收回；降权靠 downgrade-employee.ps1

故事线

  1. 换岗前：员工持有 employeeQwenpaw 管理员 Token（JWT 含 manager）→ List Tools 5 个
  2. 换岗后：安全团队只改网关策略（downgrade-employee.ps1），不换 Token
  3. 员工若备份了原 Token，Reconnect 后仅见 2 个论坛工具；强行调 hr_get_employee → 拒绝并上报安全中心
  4. managerQwenpaw 真管理员 Token 不受影响，仍为 5 个工具

无 Token

不填 Authorization → Connect。List Tools 仅 forum_list_posts。

员工 Token（employeeQwenpaw — 全程不变）

换岗前 List Tools: 5 个 · 换岗后（执行降权脚本 + Reconnect）: 2 个

在岗管理员 Token（managerQwenpaw）

降权前后均为 5 个工具

权限矩阵（换岗后 / 网关阶段 B）

工具无 TokenemployeeQwenpaw（同一 Token）managerQwenpaw

forum_create_post拒绝允许允许

换岗前 employeeQwenpaw 与 manager 相同，HR/论坛共 5 个工具（网关阶段 A）。

演示命令

  1. .\demo-rbac\scripts\start-all.ps1（阶段 A 配置）
  2. 员工 Token Connect → 5 工具 → hr_get_employee 成功
  3. .\demo-rbac\scripts\downgrade-employee.ps1
  4. 不换 Token，Reconnect → 2 工具 → hr_get_employee 被拒绝
  5. .\demo-rbac\scripts\call-forum-hr.ps1 — 依次测 forum + HR
