## 核心长期记忆

这是 Agent 的核心长期记忆文件。用户和 Agent 都可以读取、编辑和更新它。

记录经过筛选、长期有效并且未来会反复用到的信息，例如：

- 用户的稳定偏好与工作方式
- 重要决策、长期约束和持续目标
- 工具设置，例如 SSH 主机、别名和本地设备信息
- 值得长期保留的经验教训

不要把每日流水或完整会话记录复制到这里；这些内容保存在个人知识库的每日笔记中。
除非用户明确要求，不要记录密码、令牌或其他敏感信息。更新前先读取现有内容，保留用户
或其他会话写入的有效信息，并合并去重。
