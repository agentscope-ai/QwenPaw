## 联系人列表

| 称呼 | 邮箱地址 | 分组 | 备注 |
| ---- | -------- | ---- | ---- |
| 示例：妈妈 | mom@example.com | 家人 | 每周日给她汇报近况 |

## 维护指引

- 发现新联系人（收到陌生来信或用户提到新的人）时，主动补充到上表。
- 发信前先查表：把用户口中的称呼解析为邮箱地址后再发送。
- 同一称呼对应多个邮箱时，先向用户确认再发送，不要自行猜测。
