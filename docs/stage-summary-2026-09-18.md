# 阶段总结：MCP 稳定性与管理界面交互优化

日期：2026-09-18。代码基线：`fa3886af`（修复首次部署初始化链路并完善跨平台部署文档）。

本文只记录该基线之后的实际变更，不将此前已提交的多用户重构、知识库检索、部署和品牌调整重复计入本阶段。

## 一、MCP 与工具运行稳定性

按功能移植上游修复，未整版合并 upstream，继续沿用本分支的用户、智能体作用域和权限模型。

- 修复 MCP 关闭、重连时挂起 RPC 无法退出的问题，保证 AnyIO 上下文在所属任务中清理；超时清理由受跟踪的后台任务接管。
- 为重连增加指数退避、抖动和连续失败熔断，支持半开探测及停止时打断等待，减少故障服务上的重复连接。
- 工具发现遇到过期会话时尝试恢复连接，必要时使用已缓存的工具定义；工具执行不因断线自动重放，避免重复产生副作用。
- 增加 Streamable HTTP 双协议客户端，支持现代协议发现及有证据的旧协议握手回退；发现阶段的 401 由后续旧握手确认真实授权状态。
- 补齐 HTTP 客户端原子重载，凭据轮换后重新协商并清空旧工具缓存，保留凭据撤销检查。
- 打通 `http_timeout` 的前端 JSON 编辑、API 校验、配置存储和运行时传递。仅接受有限正数；省略字段保留原值，显式 `null` 恢复默认值。
- MCP 工具开关同时约束模型可见的工具列表和实际执行；审批或请求锁等待后再次检查白名单，关闭已禁用工具继续执行的缺口。
- 白名单保存后等待运行时刷新；失败时明确报告“配置已保存但运行时刷新失败”，不误报已生效。
- 父执行取消时通知并回收本地工具任务，记录中断终态；显式转入后台的任务继续遵循原有后台语义。
- 工具异常增加类型和调用位置诊断，同时避免在新增诊断中直接记录异常携带的凭据、正文和主机绝对路径。

详细配置语义、上游参考提交及适配范围见 [第二批实施说明](mcp-tool-stability-batch2.md)。

## 二、技能池发布按钮不再被悬停操作遮挡

原发布按钮位于卡片底部，与悬停出现的广播、删除操作栏重叠。

- 将发布按钮固定放在卡片右上角，状态与批量勾选置于下方。
- 保留底部广播、删除及自动更新操作，保留原发布状态和批量模式禁用规则。
- 使用浏览器检查 1440、1024、390 像素宽度下的悬停布局、按钮可点击性及批量选择行为。

## 三、创建智能体后自动更新管理列表

原流程先刷新当前用户的智能体列表，再校验创建前的技能上下文。新智能体改变了列表和权限上下文，使该校验失效，导致后续“全部智能体”刷新被中断。

- 创建或保存完成后并行刷新当前用户列表与管理员列表。
- 移除两次列表刷新之间对已结束编辑上下文的错误校验；保存前及执行期间的校验仍保留。
- 创建成功后，“我的”和“全部智能体”列表及其数量自动更新，无需用户手动刷新。

## 四、技能广播成功后自动关闭弹窗

原多用户广播流程成功后只提示结果，没有关闭广播选择弹窗。

- 广播全部成功或内容无需更新时自动关闭弹窗，并刷新技能池数据。
- 存在失败或跳过目标时保留弹窗和结果，方便用户查看原因并继续处理。
- 保留逐目标内容哈希、源版本确认和授权流程。
