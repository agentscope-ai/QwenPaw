## 已识别的独立问题

PostgreSQL 当前对 `(agent_id, content_hash)` 设置唯一约束。若配置先保存为 A、再保存为 B，之后重新保存为历史内容 A，会触发唯一键冲突并返回 500。该问题影响“恢复到任意历史快照”，但不属于本任务卡片字段校验和保真逻辑；修复涉及数据库约束或版本仓储写入策略，需要单独设计并获得确认后处理。
