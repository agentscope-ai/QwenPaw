# 四类文件归属与生成产物闭环修复

状态：用户于 2026-09-15 确认；代码、数据恢复与定向验收已完成，详见验收报告。

## 已确认边界

| 类别 | 归属与用途 |
| --- | --- |
| Agent 资料 | 智能体受管理的配置与身份资料，由管理操作维护 |
| 个人知识库 | 当前用户 × 当前智能体长期文件，只经用户明确上传或保存进入 |
| 产物 | 当前用户 × 当前智能体生成文件，记录源会话，由平台登记 |
| 临时附件 | 当前会话上传文件，支持受控保存与清理 |

早期个人知识库跨智能体授权方案已被用户后续确认的用户 × 智能体隔离要求取代。普通管理员聊天同样使用个人空间。显式代码项目保留授权编辑范围，交付物另存个人产物目录。

## 实施任务

1. 服务端派生私人会话输出目录并设置普通聊天工具工作目录；保留安装位置读取技能脚本。
2. 工具执行完成与会话结束自动登记受控会话输出；幂等、失败保留、可重试；排除中间目录。不扫描共享工作区猜测所有者。
3. 多用户发送失败禁止回退共享发送；下载、删除与保存逐次验证用户及智能体归属。
4. 文件界面展示可理解来源与源会话，保存后刷新正确个人库，处理切换竞态与操作失败。
5. 核验成都攻略会话与文件，备份、复制并登记九个文件，保留原件并核对哈希。
6. 回归隔离、幂等、失败恢复、显式代码项目、单用户兼容，构建前端并重启正式服务。

## 验收

- 同智能体不同用户、同用户不同智能体相互隔离。
- 管理员普通聊天不使用共享目录存放个人产物。
- 技能生成图片/PDF 无需调用发送工具也进入产物列表。
- 临时附件与产物可明确保存到当前个人知识库，并可再次引用。
- 重复收集不产生重复登记，失败不丢文件、不伪报交付成功。
- 成都九个历史文件复制前后哈希一致，原件保留。

目录默认值与提示词并不构成任意 Shell 的操作系统级沙箱；不将此修复表述为完整主机隔离。
