## 本项修复

1. PostgreSQL `get_run`、`list_events`、`list_tool_calls` 在用户绑定视图中增加会话成员、Agent 可用性与撤销状态条件，避免裸 `run_id` 成为访问凭证。
2. 会话重连时校验请求的 conversation ID 与 ChatManager 返回 ID 完全一致。
3. 备份 SSE、备份 500 响应和后台任务失败响应改用稳定错误码，不再回显下游异常文本。
4. 项目克隆 SSE 对 Git 输出执行凭据、宿主路径和身份标识脱敏；未知异常只返回 `project_clone_failed`。
5. 查询错误转储递归清理凭据、用户标识和宿主路径，并尝试设置仅当前进程用户可读权限；运行时错误不再把本机转储路径发送给前端。
