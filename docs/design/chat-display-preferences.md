# QwenPaw 对话显示偏好设计

> 文档类型：功能设计  
> 日期：2026-09-01  
> 状态：已实施

## 1. 目标

在“设置 → 通用 → 对话显示”中提供两个应用级偏好：

1. 工具展示方式。
2. 助手消息折叠模式。

偏好只影响 WebUI 展示，不改变会话数据、消息协议或后端执行行为。

## 2. 助手消息折叠模式

| 模式     | 行为                                          |
| -------- | --------------------------------------------- |
| 全部展开 | 按原始顺序展示所有消息，不生成过程折叠组      |
| 过程折叠 | 展示全部 text，按 text 边界折叠思考和工具消息 |
| 结果折叠 | 运行中采用过程折叠，结束后只展示最后一段 text |

审批请求和错误消息在三种模式下始终直接展示。Heartbeat 不展示。

“全部展开”只取消助手消息的外层过程分组。每条 message 继续使用原有
组件和样式。

## 3. 工具展示方式

| 模式     | 点击工具卡后的内容                   |
| -------- | ------------------------------------ |
| 卡片视图 | 使用各专用工具卡现有内容             |
| 原始参数 | 只展示后端返回的原始 Input 和 Output |

两种模式都保留工具标题、状态和操作按钮。原始参数模式默认折叠，点击
后才懒加载 Input 和 Output；专用工具卡加工后的内容不再重复展示。

字符串形式的 JSON 也会先解析并格式化，再交给 JSON 高亮组件渲染。
对于 `send_file_to_user` 等工具返回的超大 base64 字段，展示层保留完整
JSON 结构，并将数据正文替换为带字符数的占位说明，避免阻塞页面渲染；
该处理不会修改工具的实际返回值。

## 4. 默认值与持久化

- 工具展示：卡片视图。
- 助手消息折叠：结果折叠。
- 默认值不写入 localStorage，保持升级后的现有行为。
- 工具展示键：`qwenpaw_tool_display_mode`。
- 消息展示键：`qwenpaw_assistant_message_display_mode`。

旧实验键 `qwenpaw_tool_calls_default_expanded` 在保存新设置时清除。

## 5. 实现范围

- `console/src/utils/chatDisplayPreference.ts`
- `console/src/pages/SettingsCenter/GeneralSettings.tsx`
- `console/src/pages/Chat/messageDisplay.ts`
- `console/src/pages/Chat/HostBubbles.tsx`

外部插件如果完全自定义工具卡渲染，不强制继承宿主工具卡的展示偏好。

## 6. 宽屏对话边界

- “宽屏模式”归入“对话显示”，位于工具和助手消息展示选项之前。
- 宽屏消息列表与输入框采用 `clamp(20px, 2%, 32px)` 左右安全边距：
  随实际对话区域连续变化，并在打开文件面板时同步收缩。
- 移动端继续保持最少 `20px`，避免在 `768px` 断点从桌面边距突然跳到
  原有的 `8px`。
- 设置页窄屏外边距由 `14px` 调整为 Spark Design 移动端常用的 `20px`。
- Segmented 切换器按选项内容自适应宽度，不与 Select 共用最小宽度，避免
  工具展示和助手消息折叠右侧出现无效留白。
