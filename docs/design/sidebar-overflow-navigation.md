# QwenPaw 侧边栏入口溢出设计

> 文档类型：功能设计  
> 日期：2026-09-01  
> 状态：已实施

## 1. 目标

当用户启用较多内置或插件入口时，保持侧边栏导航可查找，同时避免导航
区域无限向下挤压“新建聊天”和历史会话。

## 2. 展示策略

- Agent 选择器和“聊天”入口固定展示。
- 默认快捷入口依次为“市场 / 定时任务 / 文件 / 运行配置 / 模型”。其中
  “运行配置”对应 `core.agent-config`，不包含“环境变量”
  `core.environments`；已保存的用户自定义配置保持不变。
- “收件箱”及其他所有内置、插件入口合并到一个滚动区域，不再使用
  “展开 / 收起”控件。
- 滚动区域最大高度为 `min(198px, 30vh)`，约展示 5 个入口；更多入口
  直接在区域内部滚动。
- 入口高度固定为 `36px`，间距保持 `2px`；入口增加时不压缩尺寸和间距。
- 滚动区域使用细滚动条提示可继续浏览，并使用 `overscroll-behavior`
  避免滚动直接传递给外层侧边栏。
- 当前路由对应的入口自动滚动至可见区域。
- 新建聊天和历史会话继续使用独立区域，不被扩展入口无限向下推移。

## 3. 验证

- 覆盖单一导航滚动区域的最大高度、内部滚动与滚动条提示。
- 确认旧“展开 / 收起”控件及其分组逻辑已移除。
- 覆盖 TypeScript、ESLint、Prettier 和 Less 编译检查。

## 4. 设置页分组命名

- “工作入口”调整为“智能体功能”，用于归纳文件、技能、工具、MCP、
  运行配置等当前智能体相关能力。
- “插件入口”调整为“插件功能”。
- 分组仅调整中英文展示文案，不修改所含项目、选择逻辑或侧边栏行为。
