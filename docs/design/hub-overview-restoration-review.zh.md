## 其他页面初审

1. 运行环境、凭据、审计：自定义表格的表头为 8px，内容多为 9–10px，信息密集且阅读吃力。建议统一主要文字到 12–14px，再调整行高；长 ID 保持截断和完整值查看能力。
2. 用户、模型：新页面的文字通常为 12–14px，与旧表格页面不一致。用户列表可直接打开编辑面板，模型页已有搜索、筛选与配置入口，功能组织可以保留。
3. 移动端：760px 以下隐藏 sidebarFooter 和 topbar，因此刷新、返回 QwenPaw、账户退出、主题/语言入口不可见。520px 以下导航仅剩图标，需要补可访问名称和可发现的账户菜单。这次未修改全局导航。
4. 系统设置：已有分组标签页，复杂设置采用分区卡片；小屏会改为单列。选择卡片和辅助文字仍有 9–11px 字号问题。
5. 审计日志：动作筛选列表只覆盖早期运行环境、用户和凭据操作，未覆盖模型管理事件。最近活动的资源筛选可复用现有后端查询，无需扩展 API。

本轮其他页面仅提供评审，未批量重设计或更改业务行为。
