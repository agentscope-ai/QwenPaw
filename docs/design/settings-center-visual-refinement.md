# 设置中心视觉与信息架构优化

## 1. 状态

已实施。

## 2. 目标

- 参考桌面应用设置界面，降低顶栏和导航的信息噪声。
- 用清晰的分区标题与独立卡片组织设置项。
- 保持现有设置行为、路由和偏好存储兼容。
- 继续适配桌面、平板和移动端。

## 3. 设置中心框架

- 移除全局“设置”大标题、副标题和右侧关闭按钮。
- 将“返回应用”作为左侧栏顶部的唯一返回入口。
- 搜索框放在返回入口下方。
- 左侧导航项只展示 Lucide 图标和名称，不展示描述。
- 左侧分组调整为：应用设置、智能体配置、全局设置、扩展设置。
- “智能体配置”直接展开各个智能体功能页面，不设置中间聚合页。
- 智能体管理、模型和技能池统一归入“全局设置”。
- 原“数据与安全”更名为“全局设置”，原有页面归属不变。

## 4. 通用页面

通用页面拆分为四个视觉分区：

1. 外观与语言：语言、主题。
2. 内容布局：内容宽度。
3. 对话显示：工具展示、助手消息折叠。
4. 桌面应用：关闭窗口行为、桌面模式，仅桌面运行时显示。

每个分区使用“分区标题 + 独立卡片”，不再把内容布局和对话显示
混合在同一张卡片中。

## 5. 侧边栏页面

- 页面仅保留“侧边栏”标题，不展示页面描述。
- 重置按钮放在页面标题右侧。
- 固定入口、智能体配置、全局设置、插件功能分别使用独立分区卡片。
- 全选和反选保留在对应功能分区标题右侧。

## 6. 验证

- 返回入口能够回到打开设置前的页面。
- 设置搜索仍可匹配名称和内部描述信息。
- 通用设置的所有偏好读写行为保持不变。
- 侧边栏显示、全选、反选及重置行为保持不变。
- TypeScript、ESLint、Prettier、单元测试和测试构建通过。

## 7. 实施结果

- 设置中心全局大标题与关闭按钮已移除，“返回应用”移至左栏顶部。
- 左栏项目已精简为图标和名称，内部描述仅继续用于搜索匹配。
- 原“数据与安全”已更名为“全局设置”。
- 通用设置已按外观与语言、内容布局、对话显示、桌面应用拆分。
- 侧边栏设置已按固定入口、智能体配置、全局设置、插件功能拆分。
- 设置中心左栏直接展开智能体配置的全部实际页面。
- 市场从智能体配置中移除，与收件箱共同作为固定入口。
- 内容宽度和对话显示不再共用同一卡片。
- 设置中心与侧边栏相关 43 项测试及 TypeScript 检查通过。

## 8. 智能体配置与全局设置

- 删除“资源管理”分组。
- 设置中心左栏的“智能体配置”直接列出频道、会话、定时任务、心跳、
  文件、技能、工具、MCP、ACP、运行配置、智能体统计和检查点。
- 点击上述栏目后，在设置中心内容区直接打开对应的实际配置页面。
- 智能体管理、模型和技能池从“资源管理”迁入“全局设置”。
- 侧边栏设置页继续保留“智能体配置”区域，用于控制应用侧边栏入口。
- 市场不属于智能体配置，固定显示在侧边栏，并固定排在收件箱之后。
- 固定入口不会写入用户显示偏好；旧偏好中的市场值会自动忽略。
- 定向 ESLint、Prettier 和差异格式检查通过。

## 9. 设置入口与当前智能体

- 在应用侧边栏的智能体功能卡片底部增加“更多设置”。
- “更多设置”固定在功能入口滚动区之外，功能入口增加时只滚动列表，
  不挤压或移动设置入口。
- 折叠侧边栏使用相同的 Lucide 设置图标进入设置中心。
- 打开设置中心时记录应用当前地址，“返回应用”可回到原页面及查询参数。
- 设置中心“智能体配置”分组顶部增加紧凑的当前智能体选择器。
- 选择器展示智能体状态、名称和后端类型，并复用应用全局的当前智能体状态。
- 切换智能体后保留当前设置栏目，内容区直接读取新智能体的配置资源。
- 本次相关 8 个测试文件、53 项测试、TypeScript、ESLint、Prettier
  与差异格式检查全部通过。

## 10. 智能体配置导航收敛

- 设置中心的“智能体配置”只保留频道、心跳、技能、工具、MCP、ACP
  和运行配置，沿用各栏目原有图标。
- 会话、定时任务和文件属于日常工作入口，不再重复出现在设置中心导航；
  原页面、侧边栏入口和侧边栏显示控制保持不变。
- 智能体统计和检查点属于运行观察与恢复入口，不再占用常用配置导航。
- 当前智能体切换继续位于“智能体配置”标题下方，但改为单行紧凑选择器，
  移除外层卡片、“当前智能体”小标题和常驻后端标签。
- 选择器关闭时只展示状态、智能体图标、名称和下拉箭头；后端类型仅在
  展开选项中作为辅助信息显示。
- 应用侧边栏同时保留功能卡片内的“更多设置”和最底部的设置图标。
- 769px 至 900px 宽度下，较宽的分段控件自动换到独立行，避免裁切。
- 768px 以下导航区域高度调整为 48vh，让智能体选择器和首批配置入口
  同时可见，并继续允许导航区域滚动。
- 暗色模式补充返回入口与智能体选择器的边框和文字对比度。
