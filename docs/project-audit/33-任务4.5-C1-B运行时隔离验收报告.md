# Task 4.5-C/1-B ReMe 运行时隔离验收报告

日期：2026-08-25

## 本阶段交付

- 新增 `ScopedMemoryRuntimePool`。
- 公共运行时缓存键为 `public + agent_id`。
- 私有运行时缓存键为 `private + user_id + agent_id`，不同用户不会复用实例。
- 私有运行时首次创建时登记 `agent_user_workspaces`，登记值为受控相对路径。
- 用户私有运行时关闭只影响该用户，不影响其他用户或公共运行时。
- 新增公共/私有搜索结果合并器：并行搜索、作用域标签、分数排序、同作用域同位置去重、单侧失败容错。
- `MemoryMiddleware` 从服务端构造的请求上下文传递 `actor_user_id`、`agent_id`、`run_id`，不从普通请求参数取身份。
- ReMe Light 在多用户模式下提供带请求作用域的视图：自动记忆搜索合并公共与当前用户私有记忆，自动记忆写入当前用户私有运行时。
- 旧 Legacy 模式继续使用原有单实例 MemoryManager。

## 目录与运行时边界

```text
公共 ReMe：WORKING_DIR/workspaces/{agent_id}
用户 A：  WORKING_DIR/user_workspaces/{user_a}/{agent_id}
用户 B：  WORKING_DIR/user_workspaces/{user_b}/{agent_id}
```

公共记忆仍由 Agent workspace 提供；用户自动记忆不会回退写入公共目录。

## 搜索合并行为

搜索结果返回内部结构化作用域标签：

- `public_memory`：公共记忆
- `my_memory`：当前登录用户私有记忆

普通用户不会看到其他用户的私有运行时路径、用户 ID 或私有索引目录。

当一侧索引失败时，另一侧结果仍可返回；两侧都失败时才返回失败状态。
