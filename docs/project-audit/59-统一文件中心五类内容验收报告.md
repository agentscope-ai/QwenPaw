## 验收结论

文件入口已统一为五类业务内容：临时附件、个人资料库、产物、Agent 配置和记忆。独立文件页、聊天文件卡片、聊天侧栏预览和收件箱记忆通知统一使用受控 `FileLocator`，不再向普通用户暴露物理工作区目录树。

五类内容继续使用各自既有的事实源和权限边界，没有迁移正文：

| 分类 | 归属与用途 | 页面能力 |
| --- | --- | --- |
| 临时附件 | 当前用户上传并用于会话的临时文件 | 查看、下载及原有管理操作 |
| 个人资料库 | 当前用户在当前 Agent 下维护的长期资料 | 查看及原有资料库操作 |
| 产物 | 当前用户在当前 Agent/会话中登记的输出 | 查看、下载及原有管理操作 |
| Agent 配置 | Agent 的 `AGENTS.md`、`SOUL.md`、`PROFILE.md` 等受管理配置 | 按既有权限查看和配置 |
| 记忆 | ReMe 在当前用户与当前 Agent 范围内产生的日记和沉淀 | 只读查看、下载 |

## 关键修复

1. 新增严格的文件定位协议，拒绝绝对路径、路径穿越、外站产物 URL、非法记忆作用域和非法产物 ID。
2. 文件中心默认优先显示“我的记忆”，并保留“公共记忆”回退；记忆正文在本任务中只读。
3. 聊天中已登记产物直接定位到产物记录，同一文件不会因为源文件与登记快照显示为两个逻辑产物。
4. 聊天侧栏预览与独立文件页复用同一个预览组件和定位对象，展开后保持分类、Agent、会话及文件身份。
5. ReMe 收件箱事件只携带受控相对路径、记忆作用域、记忆分区和可信来源会话 ID，不携带用户 ID 或物理绝对路径。
6. `/memorize` 和 `/dream` 通过可信请求上下文绑定当前用户、Agent、来源会话和模型授权，修复斜杠命令丢失模型权限的问题。
7. ReMe 只在记忆文件实际新增或修改时推送收件箱；内容无变化时不会产生重复通知。
