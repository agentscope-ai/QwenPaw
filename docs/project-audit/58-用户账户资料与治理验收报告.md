# 用户账户资料与治理验收报告

验收时间：2026-09-09（Asia/Shanghai）

## 结论

本次账户资料与用户治理功能已完成并通过自动化、构建、数据库和真实浏览器验收。服务运行于多用户模式，PostgreSQL Schema 已升级到 `0019_user_account_profiles`，迁移前的六个用户及其密码哈希全部保留。

## 已实现范围

- 用户表增加显示名、邮箱、手机号、部门、职位和备注六个可空字段。
- 左侧账户入口固定在底部工具栏上方；悬停或点击显示用户信息和退出登录。
- 用户信息使用居中弹窗，可修改用户名和六个资料字段。
- 用户自行修改密码必须提供旧密码；修改成功后撤销该用户所有会话。
- 退出登录使用居中确认弹窗，取消不会退出。
- 管理员用户管理支持编辑资料和重置密码；重置后撤销目标用户所有会话。
- 用户管理菜单位于插件管理下方，普通用户无管理权限。
- 账户资料修改及密码变更写入脱敏审计，只记录操作者、目标、动作、请求 ID 和变更字段名。

明确未实现的资料字段：工号、头像、直属上级、办公地点。
