# Task 4.5-C/1-A 作用域解析验收报告

日期：2026-08-25

## 本阶段交付

- 新增 `MemoryScope`、`MemoryScopeContext`、`MemoryScopeResolver`。
- 公共目录固定解析为 `WORKING_DIR/workspaces/{agent_id}`。
- 私有目录按 `WORKING_DIR/user_workspaces/{user_id}/{agent_id}` 解析，同一 Agent 的不同用户不会复用目录。
- Agent ID 只接受安全标识符；请求不能提交物理路径或路径片段。
- 新增 `agent_user_workspaces` PostgreSQL 迁移，使用 `user_id + agent_id + scope` 作为隔离键。
- PostgreSQL 仅登记受控相对路径、生命周期和索引状态，不保存记忆正文。
- 新增 `GET /api/agents/{agentId}/memory/scopes` 安全摘要接口。

## 权限摘要

| 请求主体 | 返回作用域 | 公共记忆 | 私有记忆 |
| --- | --- | --- | --- |
| owner | public + 当前用户 private | 可读写 | 可读写 |
| collaborator | public + 当前用户 private | 可读写 | 可读写 |
| user | public + 当前用户 private | 只读 | 可读写 |
| 管理员显式代管 | public | 可读写 | 不返回其他用户私有作用域 |

接口响应不包含绝对路径、其他用户 ID 或索引目录信息。
