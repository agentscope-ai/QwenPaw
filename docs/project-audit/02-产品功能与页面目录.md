# 产品功能与页面目录

## 1. 产品定位与全局交互

当前 QwenPaw 是运行在用户自有环境中的个人 AI 助手。Web 控制台包含：

- 顶部栏：品牌、版本、文档、GitHub、语言、主题及快捷设置。
- 左侧栏：当前 Agent 选择器、运行状态、聊天入口、Agent 范围菜单和全局设置菜单。
- 主内容区：基于 React Router 的页面路由。
- 可选桌面模式：多窗口工作区体验。

当前控制台运行实例显示 3 个 Agent，默认选中“默认智能体”。Agent 选择会影响聊天、工作区、技能、工具、MCP、运行配置、统计和检查点等 Agent 范围资源。

## 2. Agent 范围页面

| 菜单/路由 | 当前能力 | 主要交互 | 数据/接口范围 |
|---|---|---|---|
| 聊天 `/`、`/chat/*` | 与选定 Agent 对话，呈现文本、推理、工具调用、技能调用和历史消息 | 新建/切换对话、发送、停止、上传、重连回放、项目目录、归档/删除 | `/chats`、`/console/chat`、Agent workspace sessions/history |
| 收件箱 `/inbox` | 汇总定时任务、心跳、记忆等推送与审批事件 | 筛选、已读、批量处理、查看执行轨迹、删除 | `/console/inbox/*`、本地 inbox 数据 |
| 应用 `/apps`、`/apps/:appId` | PawApp 已安装、官方和市场入口 | 浏览、安装、打开、配置、卸载 | `/pawapps`、插件/市场服务 |
| 频道 `/channels` | 配置 Console、钉钉、飞书、QQ、Discord、Telegram、Slack、微信等消息渠道 | 启停、编辑凭据和渠道参数、访问控制 | `/config/channels`、本地配置/密钥 |
| 会话 `/sessions` | 查看渠道及控制台会话 | 查看、编辑、归档、删除、筛选 | chats/session JSON 与运行时状态 |
| 定时任务 `/cron-jobs` | 管理周期或一次性任务 | 新建、模板创建、编辑、暂停、恢复、立即运行、历史 | `/cron/jobs`、workspace `jobs.json` |

| 文件 `/files` | 浏览 Agent 配置目录、档案、日记和知识库，编辑工作区文件 | 刷新、上传、树导航、打开/保存、标签切换、记忆图 | `/workspace/*`、Agent workspace 文件 |
| 技能 `/skills` | 管理当前 Agent 已关联技能 | 搜索、同步、从池添加、上传、启停、编辑、标签、频道范围、批量操作 | `/skills`，Agent skills 与 `skill.json` |
| 工具 `/tools` | 管理当前 Agent 可用工具 | 启停、异步执行设置、工具配置 | `/tools`、Agent 工具配置 |
| MCP `/mcp` | 管理 MCP 客户端及其工具 | 新建/编辑/删除、启停、查看工具、OAuth、访问主体策略 | `/mcp`、Agent MCP 配置/凭据 |
| ACP `/acp` | 配置 opencode、Qwen Code、Claude Code、Codex 等编码代理 | 运行时检测、登录状态、模型/技能/MCP 设置 | `/config/acp`、`/harnesses` |
| 运行配置 `/agent-config` | 设置 Agent 的语言、时区、项目目录、编码、记忆、计划和安全行为 | 表单修改、运行时配置和能力开关 | `/workspace/*`、`/config/*` |
| 智能体统计 `/agent-stats` | 展示选定 Agent 的会话、消息、Token、工具和趋势统计 | 时间筛选、图表查看 | `/agent-stats`、本地统计数据 |
| 检查点 `/checkpoints` | 对 Agent workspace 建立快照并恢复 | 自动检查点、手动快照、图谱、恢复预览、选择文件、GC | `/workspace/checkpoints`、Git/快照数据 |

|---|---|---|---|

## 4. 当前认证与账户交互

当 `QWENPAW_AUTH_ENABLED` 开启时：

- 首次只允许注册一个账户。
- 登录成功返回 Bearer Token。
- 侧边栏提供账户管理和退出登录。
- 账户管理只支持修改当前单一账户的用户名和密码。
- 可撤销当前 Token 或通过轮换全局 JWT 密钥撤销全部 Token。
- 没有用户列表、邀请、禁用、重置密码、角色分配、审计查询或个人头像资料模型。

## 5. 容易混淆但必须分离的概念

- **Agent**：一套助手运行配置与 workspace，不是登录用户。
- **渠道用户 ID**：钉钉/飞书/Discord 等外部消息发送者标识，用于会话、访问控制或上下文，不是 Web 账户。
- **Session/Chat**：一次对话或渠道会话，不是租户。
- **技能池**：部署实例级共享技能来源；`/skills` 是 Agent 关联后的技能集合。
- **工具安全权限**：对 Agent 工具调用的 allow/ask/deny 和沙箱策略，不是后台管理 RBAC。

## 6. 多用户改造必须保持的原有体验

后续设计和实现必须逐页验证：路由可达、Agent 选择、数据加载、创建/编辑/删除、批量操作、流式响应、上传下载、实时状态、错误提示和权限受限态。不能只以菜单显示或 HTTP 200 作为功能完成标准。
