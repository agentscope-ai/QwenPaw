# Task 5.1 Conversation Repository 验收报告

## 结论

Task 5.1 已完成：新增统一的 Conversation Repository 领域契约，并由 Legacy JSON 与 PostgreSQL 两个适配器通过同一组行为测试。当前 ChatManager、聊天路由、SSE 和 18089 运行实例均未切换到新 Repository，因此本任务不会改变现有对话页面行为或生产事实来源。

## 实现范围

- 六类不可变领域记录：会话、消息、Run、RunEvent、ToolCall、Attachment。
- 统一异步接口：创建、读取、列表、状态收敛、幂等写入和稳定顺序读取。
- Legacy JSON 适配器：单文件聚合、原子替换、进程内写锁。
- PostgreSQL 适配器：复用既有 `conversations/messages/runs/run_events/tool_calls/attachments` 表，schema 名称白名单，异步 session factory 注入。
- 稳定冲突语义：同一消息序号或事件序号重复写入相同内容时幂等；内容不同时抛出 `RepositoryConflictError`。

## 等价契约覆盖

同一套 `_exercise_contract` 同时验证两个适配器：

1. 会话创建幂等、读取、列表、归档和软删除。
2. Run 创建、读取与完成状态收敛。
3. 消息按 `conversation_id + sequence` 幂等和冲突拒绝。
4. RunEvent 乱序写入后按 sequence 稳定回放，并保留 ToolCall 关联。
5. ToolCall 按 `run_id + call_id` 更新和读取。
6. 附件只持久化内容引用元数据，并支持幂等写入。
