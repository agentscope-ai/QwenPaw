# 记忆筛选分组与布局稳定性修复验收报告

> 验收日期：2026-09-16  
> 服务地址：`http://127.0.0.1:18089`  
> Agent：`QwenPaw_QA_Agent_0.2`

## 问题根因

记忆页面同时提供两种不同维度的筛选：一组选择“公共记忆/我的记忆”，另一组选择“日记记忆/长期记忆”。原界面没有显示维度标题，并通过 `space-between` 将两组按钮推到内容区两端。用户打开日记文件后再切换长期记忆时，远端的第二组按钮容易被理解为突然新增的重复 Tab；空列表状态又进一步放大了这种视觉错觉。

## 修复内容

1. 为两组筛选分别增加“记忆范围”和“记忆类型”标题。
2. 两组控件使用相邻、固定的左对齐布局，并以分隔线明确分组关系。
3. 在窄屏下改为稳定的上下两行布局，不让筛选项被挤到不可预期的位置。
4. 为记忆面板增加完整宽度、最小宽度和弹性尺寸约束，保证有文件与空列表两种状态使用同一内容宽度。
5. 增加语义化 `group` 和本地化无障碍名称，使自动化测试和辅助技术能准确区分两个维度。

## 验收证据

- `MemoryPanel` 专项测试：7 项通过，包含两组筛选的结构和语义断言。
- 文件中心相关测试：5 个测试文件、23 项通过。
- 生产构建：TypeScript、Vite、Monaco CSS 校验通过。
- 真实浏览器切换：切换前后筛选组数量均为 2；两组坐标与尺寸保持不变。
- 日记记忆选中状态：`我的记忆 / 日记记忆`。
- 长期记忆选中状态：`我的记忆 / 长期记忆`，空列表正常显示且页面宽度不变。
