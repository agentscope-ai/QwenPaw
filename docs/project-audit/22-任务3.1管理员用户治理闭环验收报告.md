# 纵向 Task 3.1：管理员用户治理闭环验收报告

## 1. 当前结论

Task 3.1 已完成前端、后端、真实 PostgreSQL、角色差异、会话撤销和 Legacy 对照验收，并于 2026-08-21 通过用户确认。本任务没有新增数据库表或迁移，复用 Task 2.1 已验收的 `users` 与 `sessions` 表。

## 2. 可见功能

- 管理员侧边栏新增“用户管理”，可查看用户、创建用户、启用/禁用、切换管理员/普通用户角色和撤销全部会话。
- 普通用户仍保留聊天、Agent 使用与管理、技能、MCP、频道、Token 用量等普通能力。
- 普通用户不再看到模型、用户管理、技能池、环境变量、工具后台策略、安全、系统状态、备份、语音转写、调试和插件管理。
- 普通用户直接访问 `/admin/users` 显示 403；调用 `/api/admin/users` 返回 403。

## 3. 后端设计

- `ActorContext` 只能从可信认证会话生成，忽略客户端伪造的 `user_id` 查询参数；Legacy 使用兼容管理员主体。
- `AuthorizationService` 以 capability 表达“管理员拥有普通用户全部能力，并额外拥有治理权限”。
- 用户治理 API 提供列表、创建、状态、角色和会话撤销五类操作，响应不包含密码或密码哈希。
- PostgreSQL 更新使用事务锁保护最后一个有效管理员，禁止将其禁用或降级。
- 禁用用户后立即撤销其会话；不存在用户的会话撤销明确返回 404。
