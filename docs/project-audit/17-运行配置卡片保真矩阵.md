# 运行配置卡片保真矩阵

更新时间：2026-08-26

## 1. 共同契约

| 项目 | 契约 |
|---|---|
| 配置内容源 | Agent workspace 内的 `agent.json`；PostgreSQL 只保存访问关系、配置版本、快照与哈希，不替代运行配置文件 |
| 完整配置读写角色 | Agent owner、collaborator；管理员必须通过显式“代管运行配置”入口，并携带目标 Agent ID 与 `X-Agent-Governance: runtime-config` |
| 仅使用/平台公用角色 | 只读取安全摘要；完整卡片接口前后端均拒绝，不能通过直接调用 API 绕过 |
| 普通目标 | 侧边栏当前 Agent 或 Agent-scoped 路由目标 |
| 代管目标 | URL 中确认的治理 Agent；页面只构造一个 `AgentRequestContext`，所有关联接口复用，不读取侧边栏 Agent |
| 保存并发 | 完整配置使用 `config_version`/`If-Match`；冲突返回 409，不覆盖新版本 |
| 热重载 | 保存与运行时应用分开报告；重载失败保留已保存配置并显示 `pending_reload`，允许管理员或编辑者重试 |
