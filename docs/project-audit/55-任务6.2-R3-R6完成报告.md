# Task 6.2-R/3 至 R/6 完成报告

更新时间：2026-09-04

## 已实现

- R/3：附件保留三种状态（临时、已保存、已删除）。当前用户可将临时附件保存至自己运行空间的 `documents/`，仅已保存附件可在该目录中移动，删除操作同时清理物理文件并保留元数据状态；服务端拒绝标准目录以外的路径。为防止历史数据丢失，既有 `资料/` 文件仅保留读取、移动和删除兼容，新建文件不会再写入该目录。
- R/4：个人资料库保留为独立用户目录和数据库元数据/Agent 授权，Agent 工具只在用户为该 Agent 明确授权后可用。
- R/5：产物正文在用户个人运行空间的英文 `artifacts/` 下；数据库表 `user_agent_artifacts` 保存所有者、Agent、会话、摘要、来源工具和软删除状态。`send_file_to_user` 在可信用户运行上下文中自动登记，产物列表/下载/删除接口均按当前用户与当前 Agent 过滤。
- R/6：已覆盖同一 Agent 下的双用户私有工作区、附件、产物读取与删除拒绝路径，服务端 RLS 将数据库记录与当前用户绑定。
