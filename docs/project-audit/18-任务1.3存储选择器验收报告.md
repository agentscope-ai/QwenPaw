## 切换门禁

`RepositoryProvider` 只在以下条件全部成立时才返回调用方显式提供的
PostgreSQL Repository：

1. `QWENPAW_STORAGE_MODE=postgres`。
2. 目标 Schema 存在 `alembic_version`。
3. 当前 Revision 等于 `0003_governance_operations`。
4. 调用方明确传入 PostgreSQL Repository 实现。

任一条件不成立都会失败关闭。当前项目尚未实现或注入正式 PostgreSQL 业务
Repository，因此不存在静默切库路径。

## 真实 PostgreSQL 验证

在独立临时 Schema 中验证：

```text
升级前：schema_not_initialized
升级后：0003_governance_operations
显式测试 Repository：postgres
```

验证结束后已降级并删除临时 Schema。该结果只证明选择门禁有效，不代表业务
数据已经切换。
