## 中文交互

- 默认和兜底语言使用中文；保留用户主动选择其他语言的能力。
- 中文界面的登录错误、权限错误、网络错误及通用操作失败信息不再直接显示英文后端异常或原始 JSON。
- API 错误保留 `status`、`rawMessage` 和 `detail`，用于程序判断和诊断；用户提示使用中文说明。
- 补齐 Ant Design 静态弹窗的语言上下文，以及定时任务、Git 操作、MCP、开发工具中的交互文案。
- MCP 原生 `alert` 改为应用内中文提示；ACP 自定义 Node 路径输入改为有中文确认、取消的应用弹窗。文件名、路径、模型名、用户内容和模型回答不做强制翻译。

## 登录失败提醒和管理员解锁

- 保持“60 秒内失败 5 次，锁定 15 分钟”的保护规则。
- 前四次失败返回剩余次数；第五次立即返回 `423`、结构化锁定信息及 `Retry-After`。
- 登录页显示中文次数提醒和剩余时间，锁定期间阻止重复提交。用户名切换不会误用另一账户的锁定提示；锁定检查不会延长截止时间。
- 用户名首尾空格在认证和计数中统一处理，避免同一账户出现不同锁定键。
- 后台用户列表显示登录锁定状态，管理员可通过 `POST /api/admin/users/{user_id}/unlock` 定向清除该用户的失败计数和临时锁，并产生审计记录。
- 解锁不修改密码、不启用停用账户、不清除其他用户的锁或共享 IP 防护；普通用户无权执行。审计失败时不解锁。
- 登录页增加“管理员已解锁，重新尝试”入口，仅恢复本地提交能力，仍须由服务器正常认证；服务器仍锁定时继续显示锁定状态。

部署边界：沿用现有进程内存限流，适用于当前单服务进程部署。多进程或多副本需先接入共享限流状态，才能保证跨实例查询和解锁一致。登录保护没有新增数据库结构；后续持久历史访问修复包含 `0024_owner_history_durability` 增量权限函数迁移，详情见下文。

## 本人中文 PDF 与相关权限链路

本地复现了与反馈现象一致的缺陷：发送工具的结果同时包含归档文件的 `file://` 路径、中文 `DataBlock.name` 及稳定产物下载链接，前端遗漏 `name` 并优先使用文件路径；部分 API 链接还会被错误包装为文件系统预览链接。

- 优先使用发送结果中唯一、合法的稳定产物 ID 下载链接，保留中文文件名。
- 区分文件系统路径与已有 API 链接，按路径段编码；服务端仅使用路由层的一次解码，保留真实含 `%` 的文件名。
- 受保护文件预览、媒体探测和浏览器下载统一复用认证请求层，发送明确的 Agent 作用域，支持令牌续期，剔除历史 URL 中的过期 token。
- 外部媒体链接不接收平台认证头；切换账户后取消旧预览或下载结果。原生保存对话框返回后，也会重新检查身份，防止继续使用旧凭据。
- 稳定产物下载支持 `GET`、`HEAD` 和 PDF `Range` 请求；文件卡优先用 `HEAD` 探测已支持的接口。
- 通用工作目录路径预览仍校验本人归属、Agent 作用域和实时使用权限；它不作为已交付产物的永久访问入口。已登记产物使用稳定 ID，直接依据当前登录用户与数据库所有者核验，不受当前选择的 Agent 或原 Agent 使用资格变化影响。其他用户（包括平台管理员）不能因此读取产物；用户已删除的产物和路径穿越继续被拒绝。
- 未开放任意历史共享目录：只有有效本人附件登记的旧文件可兼容访问，不能仅凭聊天中出现一个路径就认定有权读取。

线上对话 `b79144ea-1810-4bb6-9a33-45930ae3d9bb` 及其 PDF 原件本轮未连接核验。授权正式处理后，应核对该文件的产物登记、所有者、Agent 和实际文件位置；若历史元数据缺失，需基于归属证据修复，不能直接放开目录权限。

## 对话与产物的持久归属

用户拥有自己创建的对话和已登记产物，无须手工授权。这里的所有者权限与智能体的运行资格分开：智能体停用、撤销使用资格或软删除后，本人仍可读取未删除的历史对话和产物，但不能因此继续运行智能体或读取他人的内容。

- 稳定产物下载及本人产物列表依据持久所有者记录，不再要求原智能体可以运行，也不依赖当前选择的智能体。
- 历史消息展示时，依据本人、原智能体、原会话与有效产物登记，把旧主机、过期令牌和可确认的归档路径转换为稳定产物 ID 链接；不按同名文件猜测归属。
- 已交付的 `artifacts/.registered/` 快照从检查点回滚范围中排除，避免恢复工作文件时删除已交付文件而留下无效数据库登记。
- 重复交付会核验已登记快照。原件内容哈希一致且快照缺失时可补齐原快照，继续使用原产物 ID；不覆盖内容冲突，不恢复用户已删除的产物。
- 原智能体不可运行时，只组装历史读取入口，不启动模型、工具、记忆或运行环境。
- 会话详情接口返回授权后的 `agent_id`，前端直接按会话 ID 恢复原归属；不再因可用智能体列表为空而停在加载页。智能体列表刷新和选择器不得把正在查看的本人历史对话切回其他智能体。原智能体仍可运行时保留正常使用资格，只有实际失去运行权限时才显示历史只读。
- 已由详情接口确认的本人历史导航选择仅暂存在内存中；主动切换智能体或退出账户时清除，不写入持久授权，不把不可用智能体改成可运行。
- `0024_owner_history_durability` 调整 PostgreSQL 会话读取权限函数，同时约束写权限；不更新历史业务数据。迁移的本地验收使用专用临时 PostgreSQL 容器，未应用于已有本地业务数据库或正式数据库。

尚未登记、物理文件已被删除或迁移时遗漏的历史文件，不能仅凭一段聊天文字自动赋予权限或重建内容。正式修复这类旧记录需要先核对原件、数据库归属与备份。
