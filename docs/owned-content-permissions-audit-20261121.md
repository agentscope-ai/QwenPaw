# 用户内容持久归属与跨模块权限检查

日期：2026-11-21。承接本地中文交互、登录保护及历史产物修复。本轮仅修改本地代码并在隔离环境验证，没有提交、推送、部署或修改业务数据库。

## 统一规则

用户创建的对话、交付产物、上传资料、私有记忆和本人任务记录，读取时依据可信登录身份及持久归属。切换导航、重新登录、原智能体停用或撤权，不应撤销本人对已有内容的读取权。共享应用的运行、公共资料、审批决定、发布审核、配置修改和工具执行继续遵循各自的实时授权。

稳定对象 ID 从数据库取得所有者及原作用域；显式智能体路径仍要求作用域一致。路径本身、文件名、前端传来的用户 ID、管理员身份，都不能代替本人内容归属核验。

## 检查范围与结果

| 模块 | 确认的问题与处理 | 保留的权限边界 |
| --- | --- | --- |
| 对话与产物 | 延续上轮稳定 ID、本人历史只读恢复与交付归档保护；兼容本人已登记产物的旧路径预览 | 其他用户不能读取；普通工作文件仍需实时 Agent 使用权 |
| 个人资料库 | 列表、正文、下载和索引状态不再要求原 Agent 可以运行；稳定资料 ID 根据数据库原归属读取 | 上传、导入、移动、删除、索引重建保留原操作权限；索引不能提供授权 |
| 聊天附件 | 列表和下载保留本人读取权；所有 Agent 角色的新增聊天附件均按上传用户隔离；下载、运行引用和导入复用受控解析 | 已删除、错误所有者、错误 Agent、目录穿越和未登记路径拒绝 |
| 旧附件路径 | 原路径失效后可能继续把嵌套的 `workspaces` 当成另一个根；修为确认一个根后失败即拒绝，嵌套同名目录只作普通相对路径 | 不根据同名共享文件替代原件；没有可信原件时返回不存在 |
| 私有记忆 | 本人摘要、日记和长期记忆读取不依赖 Agent 当前资格；读既有文件时不创建目录或启动记忆服务 | 公共记忆、私有写入、重建索引、Memorize/Dream 运行仍需原授权 |
| 后台任务与工具结果 | 已结束的本人结果可独立读取，不重新取得 Agent 运行资格 | 运行中任务、流式控制、取消、延时等仍校验实时权限 |
| 定时任务 | 本人列表、详情、历史直接读持久记录；结果及失败通知发给任务所有者，修复误发 Agent 所有者 | 启用、执行、改配置和授权保留原约束；其他用户不能借本人入口读取 |
| 短推送与收件箱 | 短推送先按服务端接收人过滤再消费，不能知道会话 ID 就读取或清除别人的消息 | 短推送仍为原有短时缓存，持久通知由收件箱承担 |
| 技能发布申请 | 补申请人查看本人申请和固定快照的入口，沿用现有面板提供“我的发布申请”只读视图 | 管理员可审核用户主动提交的快照；其他普通用户不可读；通过与拒绝仍限管理员 |
| 共享应用与发布 | 核查本人草稿、版本及发布记录，无须原 Agent 正在运行；既有所有者检查有效 | 安装、使用和新的发布仍检查当前授权；管理员不因管理身份获得他人私人草稿 |
| 文件中心与预览 | 同一 Agent 切换账户时，清空旧记忆、预览、选中项及未完成结果；同用户令牌续期不误清空；受保护的显式 Agent 文件链接使用链接自身作用域 | 账户切换后不展示旧账户内容，不把认证头发给外部 URL |
| Windows 路径 | Python 3.11 的 junction 未被 `is_symlink()` 识别；统一使用 `lstat` 判断符号链接及目录联接，先检查原始路径再解析 | 覆盖附件、产物、私有工作区、应用工作区、记忆、资料库及其索引；普通云盘占位文件不一概拒绝 |
| 审批、模型、MCP、工具配置 | 核查权限入口并纳入隔离回归；这些操作没有本人持久读取豁免 | 不放宽审批决定、Agent 编辑/使用资格或运行配置权限 |

外层 Agent 路由只对明确的本人读取入口放行到对象授权处理器，不缓存运行角色，不允许写方法、治理头或公共记忆通过该规则。

## 验证方式

- 针对附件嵌套目录问题，先复现 3 项失败，再验证拒绝错误路径且本人合法嵌套文件仍可读取。
- 使用 Windows 合成目录复现 6 项 junction 失败；修复后验证用户根、Agent 根、私有记忆、资料库和索引隔离，目录联接只在测试临时目录内创建和移除。
- 普通用户、本人、其他用户、管理员、原 Agent 不可用、显式作用域不一致及撤权后的运行控制分别验证。
- PostgreSQL 使用独立 `qwenpaw_test_*` 数据库及每个用例独立 schema；不使用业务库。
- 浏览器使用真实前端构建、合成文件和隔离 API，检查预览、标签页、菜单返回、刷新及重新登录。

## 第二轮独立复核

根据追加要求，重新复核读取入口之外的失败回滚、旧接口、导入导出和异步界面状态，确认并处理以下遗漏：

| 遗漏 | 本地处理 |
| --- | --- |
| 附件保存、移动、删除在元数据异常或取消时丢失原件 | 失败恢复原件；删除先暂存再更新；目标独占创建，不覆盖已有或竞态文件；核验返回记录的对象 ID 与所有者 |
| 产物删除遇到 Windows 文件占用后，原件还在却被登记为已删除 | 两种删除入口共用补偿处理；仅恢复本人的本次删除时间戳匹配的记录，避免恢复其他删除操作 |
| 自定义旧工作区附件被统一目录解析错误拒绝 | 仅兼容同 Agent 的现有登记根、允许的附件子目录与匹配的原始 SHA-256；原 Agent 停用不影响此读取，不放开任意绝对路径 |
| 旧附件链接和按需展开工具结果仍含旧主机或过期令牌 | 根据有效本人附件 ID 重绑当前站点；正文、图片、音视频、Markdown 及工具结果使用相同规则，原始持久消息不被改写 |
| ZIP 导出及目录列表绕过 Windows 目录联接防护，包装目录 ZIP 导入目标检查不一致 | 遍历时不进入链接目录；按真正解包根预检所有目标，再执行覆盖，阻止目标目录联接越界 |
| Agent 通用文件/ZIP 入口能绕过对象授权访问旧 sessions、chats、附件等运行数据 | Agent 配置根隐藏并拒绝这些旧私人运行路径；导出排除、导入及上传拒绝覆盖；本人私有项目目录和明确的归属读取入口仍可使用 |
| 收件箱详情在切账户或连续切消息后被旧成功/失败结果回填 | 详情选择、关闭、身份变化使旧请求失效；立即清除旧正文和模态框 |
| 定时任务列表、编辑、历史、确认框及乐观回滚跨账户残留 | 用户、Agent、权限或查询范围变化清空局部状态，阻止旧异步结果、回滚和后续授权步骤；仅关闭本页确认框，同账户续期保持内容 |
| 多用户受保护响应缺少明确的私人缓存策略 | 受保护 API 与登录认证响应统一使用 `private, no-store`，保留原 `Vary` 并增加认证头及 Cookie 区分；静态资源继续使用原缓存策略。这是已确认的响应头缺项，本轮没有声称复现了真实浏览器缓存泄露 |

## 后续边界

本轮不把平台管理员设为所有私人文件的读者。管理职责涉及的审核快照、运行配置治理有明确入口和独立授权，不等于任意读取用户对话、资料或记忆。

旧文件缺少归属登记、原件已删除或迁移时遗漏时，不能仅依据聊天文字或同名文件恢复授权或内容；需要核对原件、历史记录及备份。线上指定 PDF 尚未连接核验。提交、推送和正式处理仍等待用户后续授权。
