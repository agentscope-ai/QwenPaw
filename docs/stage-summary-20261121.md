# 本阶段优化总结与发布范围

日期：2026-11-21。基线：`39f69532397713fe7164f791e6a0b447ce158615`。用户已明确要求总结、使用中文提交并推送到 origin，以及更新正式服务端；本次不向 upstream 推送。

## 个人资料库索引基础设施

- 增加按用户和智能体作用域隔离的 SQLite 派生倒排索引、文档内容与词项增量维护、状态查询及重建入口。
- 索引损坏或旧数据尚未建索引时可恢复；索引不是授权依据，PostgreSQL 继续保存可信归属。
- 文档变更、从产物保存、移动和删除同步维护索引；缓存和派生索引包含私人内容，排除在 Git 与镜像之外。
- 本阶段不新增向量模型，不合并 upstream，不升级 ReMe 或核心依赖，也不恢复已撤销的第四阶段模型路由改动。

## 中文交互与账户保护

- 默认中文，统一接口错误、交互弹窗、文件与工具配置提示，避免把内部英文错误直接交给用户。
- 登录显示失败后剩余尝试次数、锁定状态与倒计时；仍执行原有失败窗口和锁定策略。
- 后台用户管理增加定向解锁及审计，保留密码、账户停用状态和其他防护约束。

## 本人内容的持久归属

- 本人未删除的历史对话、产物、附件、个人资料、私有记忆和已完成任务，根据可信身份及持久归属读取。
- 原 Agent 撤权、停用或软删除，不应撤销本人对既有内容的读取权；恢复读取不会启动运行时或重建记忆服务。
- 其他用户和管理员不会因此取得私人内容访问权。共享阅读、运行、写入、审批和配置治理继续检查实时资格。
- 新增 `0024_owner_history_durability`：替换现有会话读写权限函数，不批量改写历史数据；本人历史读取与实时写入约束分开。

## 文件交付、路径和生命周期

- 统一历史附件与产物链接投影，兼容中文文件名、旧主机和过期令牌，以及正文、音视频和延迟展开工具结果。
- 预览、下载与 Range 请求复用对象授权，不依赖当前导航选中的 Agent；不会把认证信息发给外部链接。
- 附件保存、移动和删除遇到异常或取消时恢复原件；目标独占创建，防止覆盖。产物物理删除失败时只补偿本人的本次删除记录。
- 旧自定义工作区附件仅在 Agent 登记根、允许目录和原始内容哈希均匹配时兼容读取，不猜测同名文件归属。
- 检查点不回收已归档交付文件；Windows 符号链接和目录联接使用统一检查。
- 通用 Agent 文件入口不能绕过对象授权读取旧私人运行目录；ZIP 导出排除这些数据，导入在写入前检查全部实际目标。

## 跨账户状态和任务隔离

- 文件中心、预览、收件箱详情、定时任务列表与编辑状态按身份和作用域隔离，账户变化立即隐藏旧内容。
- 请求序列校验阻止旧成功、失败和乐观回滚覆盖新账户状态；同账户令牌续期不误清空。
- 短推送按接收人过滤后消费；定时任务结果和失败通知交付给任务所有者。
- 申请人可只读查看本人技能发布申请和固定快照，管理员审核入口保持独立权限。
- 多用户受保护响应及认证响应增加 `private, no-store`，保留并补齐 `Vary`；静态资源维持原缓存策略。
