# 统一文件中心的五类内容

本文记录 2026-09-15 确认并实施的多用户文件边界。`WORKING_DIR` 指正式服务配置的 `working_dir`，不固定为项目源码目录或用户的 `.qwenpaw`。部署路径配置见 [部署说明](deployment.md)。

| 页面 | 用途 | 隔离与写入方式 |
| --- | --- | --- |
| 临时附件 | 会话上传的文件 | 当前用户、当前智能体和上传会话；用户可显式保存到个人资料库 |
| 个人资料库 | 跨会话长期资料 | 用户 × 智能体独立；明确上传或点击保存才进入，不因生成文件自动写入 |
| 产物 | 图片、PDF、笔记等交付文件 | 用户 × 智能体隔离，记录源会话；可下载、删除或显式保存到个人资料库 |
| Agent 配置 | 智能体身份、规则等受管理配置 | 只展示工作区中的受管理配置子集；按既有 Agent 权限只读或编辑 |
| 记忆 | ReMe 从对话中提取并整理的长期记忆 | 分为当前用户私有记忆与 Agent 公共记忆；正文只读，索引异常不影响查看已有文件 |

五个页签按“临时附件、个人资料库、产物、Agent 配置、记忆”固定排列。独立文件页、聊天文件预览展开态和收件箱记忆跳转复用同一逻辑文件定位，不再在普通文件流程中显示“工作区、档案、日记、知识库”这组内部导航。详细边界见[统一文件中心设计](superpowers/specs/2026-09-16-unified-file-center-design.md)。

## 记忆与资料的区别

个人资料库保存用户明确上传或主动保存的长期参考资料，系统不会把生成产物或 ReMe 记忆自动放入资料库。记忆页只读展示 ReMe 管理的 Markdown：

| 页面名称 | 作用域 | 内部类型 | 说明 |
| --- | --- | --- | --- |
| 我的记忆 / 日记记忆 | private | daily | 当前用户在当前 Agent 下按日期保存的对话日记 |
| 我的记忆 / 长期记忆 | private | digest | 当前用户在当前 Agent 下由 Dream 提炼的长期主题记忆 |
| 公共记忆 / 日记记忆 | public | daily | 当前 Agent 按日期保存的公共对话日记 |
| 公共记忆 / 长期记忆 | public | digest | 当前 Agent 由 Dream 提炼的公共长期主题记忆 |

普通用户默认打开“我的记忆”；没有私有作用域时才回退到“公共记忆”。管理员代管其他 Agent 时只能读取其公共记忆，不能借助管理员身份读取其他用户的私有记忆。收件箱中的 Auto-memory 与 Auto-dream 通知会携带受控相对路径；检测到具体文件时可以直接跳转到文件中心，来源会话仍存在时也可以返回原对话。

## 个人资料库检索

个人资料库按当前认证用户和当前 Agent 过滤后再检索，不跨用户或跨 Agent 读取。检索采用两阶段召回：先按文件名和相对路径匹配；全部查询词均命中文件名时直接作为高优先级候选。文件名只命中部分查询词时，再提取正文，并要求每个查询词至少在文件名或正文中命中。排序时完整文件名命中优先于部分文件名和纯正文命中；命中结果只返回摘要和文档 ID，Agent 再通过只读工具读取正文。

当前可提取和检索的格式包括：

- 文本与结构化文本：`.md`、`.markdown`、`.txt`、`.csv`、`.tsv`、`.json`、`.jsonl`、`.yaml`、`.yml`、`.toml`、`.xml`、`.html`、`.htm`、`.log`、`.rst`、`.ini`；
- PDF：`.pdf`，提取文件中已有的文本层；
- Office Open XML：`.docx`、`.pptx`、`.xlsx`；
- OpenDocument：`.odt`、`.odp`、`.ods`。

扫描图片型 PDF 暂不执行 OCR；旧二进制 Office 格式 `.doc`、`.ppt`、`.xls` 需要先转换为上述现代格式。解析只产生内存中的 UTF-8 检索文本，不修改或替换用户上传的原文件。

## 普通聊天的目录

控制台普通多用户聊天的 Shell 和文件工具默认工作目录为：

```text
WORKING_DIR/
  user_workspaces/<用户 UUID>/<智能体 key>/
    artifacts/<会话 UUID>/       # 当前会话输出
      .work/                    # 中间文件，不自动登记
    artifacts/.registered/      # 已登记文件快照，由平台维护
  user_libraries/<用户 UUID>/<智能体数据库 UUID>/
```

管理员、智能体所有者、协作者的普通聊天也使用自己的会话输出目录。多用户身份和目录由服务端确定，请求方不能用路径字段指定其他用户目录。

技能从安装位置读取脚本，输出到当前私人会话目录。脚本支持 `--output-dir` 或 `-o` 时应传此目录的绝对路径；缓存、临时文件和待修改的中间版本放在 `.work/`，完成后再写入输出目录。不要把个人输出路径硬编码为智能体共享工作区。

明确选择的代码项目仍可作为编辑目录，但必须在授权项目范围内；交付文件应写入上述私人输出目录，或通过发送文件工具复制归档。平台不会扫描整个代码项目，把所有代码文件当产物。

具有服务端绑定用户身份且能验证会话写权限的渠道请求采用相同私人目录。没有可信会话标识的自动化或旧渠道请求不会被猜测归属；单用户保持兼容行为。

## 自动登记与恢复

工具实际执行结束后收集当前私人会话目录，后台工具完成也触发；会话结束再次收集。因此生成文件不依赖智能体一定调用 `send_file_to_user`。普通目录中的最终输出会被收集，隐藏目录、`.work`、缓存、临时文件等除外。

按用户、智能体、源会话及内容摘要幂等登记。发送同一内容或重复收集不会新增重复记录。归档保存独立快照，同名但不同内容不会静默覆盖旧快照。`artifacts/.registered/` 是已登记产物的受控快照目录，不代表第二份逻辑产物；文件中心只以数据库中的一条登记记录展示。已删除内容有墓碑记录，自动扫描不会将其复活；用户明确重新发送可以形成新登记。

登记失败保留源文件；“文件 → 产物 → 检查未登记文件”可重试当前用户、当前智能体所属会话的受控目录。界面只把本次新增记录计为新登记。多用户发送工具归档失败会返回错误，不再回退为共享目录普通发送。

历史共享目录不会自动推断所有者。2026-09-15 已对确认会话 `de307e1e-a799-4323-8fbb-4699dea2990c` 的成都攻略九个文件备份、复制和登记；原件保留。其他历史文件需有可核验的会话归属后再恢复。

## 权限与验证边界

下载、删除、保存个人资料和再次引用均按当前认证用户与当前智能体验证。个人资料库不需要再对其他智能体授权；切换智能体后展示该用户在新智能体下的独立资料库。

Agent 配置仅包含 `AGENTS.md`、`SOUL.md`、`PROFILE.md`、`MEMORY.md`、`HEARTBEAT.md` 等平台允许管理的配置文件，不等于完整工作区。ReMe 的 `memory/`、`digest/` 和内部会话、元数据目录不通过 Agent 配置页暴露。

上述应用层目录和文件 API 边界并不等于操作系统级 Shell 沙箱。具备任意 Shell 执行能力的进程仍需要独立账号、容器或其他主机隔离手段限制其系统权限。
