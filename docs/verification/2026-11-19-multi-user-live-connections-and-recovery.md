2026-11-19 完成开发工作区验收，11 月 19 至 20 日从暂存区导出候选源码复测，比较基线为 `75982e358`。本次提交覆盖多用户权限、跨智能体委托、跨进程任务接管和六个自带插件的 Worker 迁移。所有验证在本地完成。

## 提交范围

- 设备退出、用户停用、成员和插件授权撤销均沿用现有权限记录。聊天状态、工具输出与控制命令、计划、用户输入和后台结果按所属用户、智能体和相应会话校验。多用户模式关闭绕开现有定时任务授权服务的旧入口，运行诊断要求平台设置权限。
- 同一智能体并发组装工具时，资源策略跟随各次请求。子任务的工具和技能名单只能在父级授权内收窄。资料库继续按成员和智能体读写，新建同名文件采用排他发布。受限子任务不会自动调用未获准的资料工具，长 PPT 指令不再被原样当作显式检索词。
- 独立模型路由、能力编辑、重排、检索评测界面和索引重建属于其他阶段，留在本地。此提交中模型准备逻辑的改动用于固定目标智能体的授权及恢复后台任务时的选择行为。未加入线上配置、证书、业务数据、演示文件或原始运行日志。

## 两个普通成员的原连接

两个普通成员加入同一个智能体，各保持七条真实 TCP 连接。覆盖聊天输出、重连回放、运行状态、计划、待确认输入、工具输出和工作区文件变化。两名成员使用相同的业务会话字符串，各自持有自己的数据库会话和文件。管理员只负责停用和移除操作。计时从撤权接口返回或外部数据库提交后开始，到受影响的最后一条原连接读到 EOF 为止。常规接口场景还生成撤权后的新业务事件，断言 A 没有收到，B 的原连接仍能收到自己的新事件。独立进程场景测量空闲连接能否主动关闭。

| 本地操作 | 专项复测，七条连接全部关闭 | 后端综合回归，同场景 |
| --- | ---: | ---: |
| A 退出当前设备 | 7.07 毫秒 | 45.87 毫秒 |
| 管理员停用 A | 12.92 毫秒 | 41.07 毫秒 |
| 管理员从智能体移除 A | 5.20 毫秒 | 47.37 毫秒 |
| 独立数据库进程移除 A | 4.21 秒 | 4.16 秒 |

以上为两次本地实测，不能当作线上延迟承诺。这是并发隔离验收，未测商业模型配额下的最大同时在线人数。B 刷新访问令牌后沿用原连接。A 单设备退出后同账号另一设备仍可接收，账号停用或成员资格移除则同时影响两台设备。还覆盖刷新 Cookie 已缺失、与另一个账号 Cookie 混在同次退出请求、浏览器延迟执行旧设备退出请求。旧设备凭据与浏览器当前账号分开处理。

同进程撤权在数据库提交后通知对应订阅。其他进程修改权限时，每 5 秒重新检查设备、账号、智能体和对应插件的有效授权。数据库检查期间暂停发送，查询失败或超过 3 秒即关闭。设备与授权范围相同的连接共用检查，验收中两人加一个额外设备的 15 条连接首次共触发 3 次设备检查。5 秒的周期可能留下短暂的跨进程权限传播窗口。

计划的实时广播、快照和订阅按用户和智能体隔离。技能优化流验证编辑权限，克隆流停止时清理为本次请求启动的子进程。插件授权可单独撤销。管理员从全员改为仅 B 时，A 的看板原连接在 0.37 毫秒后关闭，重新连接返回 404，B 的原看板连接和 A 已获准的另一插件继续工作。由独立数据库进程更改插件授权，最近两次复测分别为 2.80 秒和 4.90 秒。以上使用真实看板后端与本地 TCP。

## 跨智能体调用和进程退出

- 平台在同步调用、后台提交和结果回查时使用同一套身份及资源授权。普通成员须能使用来源及目标智能体，还须具有父会话和指定目标会话的写权限。后台句柄绑定创建人和父会话。用户退出、停用或失去成员资格会影响后续派发与回查。固定发布版本的会话不能借由委托跳转到草稿智能体。原有基于共享 Git 工作树的 fork 继续保持多用户禁用。
- 为 Console 后台任务新增迁移 `0023_console_tasks`。执行前保存任务及所属身份，工作进程通过数据库租约认领。尚未进入执行的任务可以重新认领。已开始执行的任务丢失租约后标记为中断，查询时提示先核对已写文件或外部操作，再由用户决定是否提交新任务。过期持有者无法覆盖后来结果。避免重复执行的范围是同一任务 ID 的自动接管。主动再次提交同一请求会创建新任务。
- 双进程实测覆盖认领后退出、执行中退出、重复认领、过期进程迟到写回、跨进程结果查询和不同所有者隔离。租约默认为 45 秒，后台扫描间隔最长 10 秒，已结束任务结果保存 7 天。跨进程能力限于该任务队列。聊天实时订阅与等待用户输入仍由建立它们的进程服务，进程重启后浏览器需要重连。
- 工作进程开始处理一条记录时起算其超时预算。准入或设备复核阶段超时返回 `task_admission_timeout`。进入执行后超时返回 `task_execution_timeout`，提示先核对可能已产生的结果。后台记录保留失败原因，同一个超时任务不会被重新认领。
- 修复了模型配置热重载与聊天准入交错时出现的 500。请求取得工作区后至任务挂入跟踪器期间保护该实例。换代时重新验证设备与资源权限，旧工作区等待所属请求结束再释放。
- 断开订阅和取消后台执行是两种独立操作。已排队的 Console 任务在派发前重新鉴权，结果查询也重新鉴权。已经进入模型或工具的独立后台任务仍可能继续执行。撤权之后的连接不能继续读取受限结果，已发生的文件写入或外部调用也不会逆转。
