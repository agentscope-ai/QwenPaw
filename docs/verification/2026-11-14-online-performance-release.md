## 实现内容

### HTTP/2 与请求可观测性

- 备份原 Nginx HTTPS 站点配置，再增加 `http2 on`，`nginx -t` 通过后平滑重载。
- 浏览器至 Nginx 使用 HTTP/2 多路复用；现有 Nginx 至应用的 HTTP/1.1 代理及 SSE 关闭缓冲配置继续使用。
- 增加独立的 `/var/log/nginx/agent-timing.log`：记录请求 ID、方法、无查询字符串的 URI、状态码、请求总耗时、上游连接/响应头/响应耗时、协议和响应字节数。
- API 响应增加 `X-Request-ID`，代理请求传递同一 ID。日志不记录 Authorization、Cookie 或 URL 查询令牌。
- 保留已有静态资源 gzip、带哈希资源长期缓存、首页不缓存，以及未认证业务接口 401 行为。
- 仓库新增两个配置片段：`deploy/nginx/agent-request-timing.conf` 用于 http 上下文，`deploy/nginx/agent-http2-performance.conf` 用于 HTTPS server 上下文。二者不能混放到相同配置上下文。

### 模型元信息读取合并

新增 `console/src/api/modelReads.ts`，模型目录、默认模型、会话模型的 GET 统一经过它。

- 相同请求的并发调用共享一个 Promise；成功结果仅复用 1 秒，减少多个组件相邻初始化产生的重复读取。
- 键包含完整 API URL、认证代次、用户 ID 和 Agent。Agent 请求头在调用时固定，切换上下文不会把等待中的请求发给其他 Agent。
- 切换模型前后、登录身份变化时立即失效；失效前的迟到结果被拒绝，不能覆盖新的选择。
- 超时、403 等失败不缓存；保留最多 64 个条目，避免浏览大量会话后无限增长。
- 此缓存仅用于元信息。实际发送时，服务端继续执行现有模型和会话权限检查。
- 模型切换 PUT 仍是原有写操作，没有自动重试或模型降级行为。

### 状态长连接

改造 `console/src/api/sessionEventStream.ts`，复用原有解析与重连生命周期。

- 同一认证代次、Agent 和订阅主题共用一个传输连接，多个面板共享事件分发。
- 卸载一个面板不会关闭其他面板正在使用的连接；最后一个订阅者离开时才关闭。
- 标签页隐藏或浏览器离线时关闭订阅并暂停重连；恢复可见或上线后重新连接。
- 恢复可见时，原有会话资源轮询立即补读状态快照，弥补隐藏期间错过的状态事件。
- 保留连接建立 15 秒超时及断线退避；新增连续 65 秒未收到任何流数据时断开并重建连接。服务器原心跳间隔为 30 秒。
- 身份切换、Agent 切换后的订阅和迟到事件隔离保持生效。

本次按主题复用，没有新增后端事件总线或跨标签页主从协议。一个可见页面仍可因实际功能需要订阅不同主题，后台隐藏页面释放连接；HTTP/2 解决同域 HTTP/1.1 连接槽限制。

### 超时体验

模型信息查询超时会显示中英文可重试提示，说明本条消息尚未提交，并返回明确的 504。输入清理仍发生在模型预检成功之后，失败时保留输入。保留原来的 30 秒请求上限；没有通过延长计时器掩盖排队。
